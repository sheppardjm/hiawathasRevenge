  **3. JS changes — observe all three sub-sections independently:**

  Replace the existing `<script>` block. The current script selects a single `[data-bg-fade]` element. The new script must select ALL elements with `[data-bg-fade]` and observe each independently:

  ```html
  <script>
    // VIS-04: Independent background fade per sub-section
    if (!window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
      const sections = document.querySelectorAll('[data-bg-fade]');
      if (sections.length > 0) {
        const observer = new IntersectionObserver((entries) => {
          entries.forEach(entry => {
            entry.target.classList.toggle('bg-visible', entry.isIntersecting);
          });
        }, { threshold: 0.15 });
        sections.forEach(section => observer.observe(section));
      }
    }
  </script>
  ```

  Key differences from the old script:
  - `querySelectorAll` instead of `querySelector` — finds all three sub-section wrappers
  - `sections.forEach` to observe each one independently
  - Threshold raised slightly to 0.15 (15% visible before triggering) for a more natural feel with smaller sub-sections
  - The single IntersectionObserver instance handles all three — efficient, no need for three separate observers
  - Still bidirectional (toggle, not one-shot)
  - Still guarded by prefers-reduced-motion check
