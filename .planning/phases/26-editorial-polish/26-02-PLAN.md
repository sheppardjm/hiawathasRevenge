  **Approach:** Add three absolutely positioned background image divs inside the `.hiawatha-section`, one for each sub-section. Each has `position: absolute`, `opacity: 0`, and a `transition: opacity 1.2s ease-in-out`. An IntersectionObserver toggles a `.bg-visible` class.

  In the HTML of HiawathaExplainer.astro, add a `data-bg-fade` attribute to the `.hiawatha-section` element:

  Add CSS for the background fade. Since the section uses a magazine editorial grid and the children need `position: relative` + `z-index: 1` to layer above the background:

  ```css
  /* VIS-04: Scroll-driven background image fade */
  .hiawatha-section {
    position: relative;
    overflow: hidden;
  }

  .hiawatha-section::before {
    content: '';
    position: absolute;
    inset: 0;
    background-image: url('/images/thumbnails/thumb_Eo6Lpv5a2onA-EMkS4BGrkQOHMQb4rwDbey7kfJDAZc-1536x2048.webp');

    position: relative;
    z-index: 1;
  }

      transition: none;
      opacity: 0.04;
    }
  }
  ```

  Use an existing thumbnail image for the background — the low-res WebP is small enough to not impact performance. Pick a forest/trail shot that provides atmospheric texture at 4-6% opacity.

  **Note on image selection:** Use any thumbnail from `/images/thumbnails/` that depicts forest scenery. If the specific thumbnail referenced above doesn't exist at build time, substitute another — the critical requirement is a forest/trail atmosphere image at very low opacity (0.06), not a specific image.

  Add a `<script>` block for the IntersectionObserver. This observer must NOT disconnect after first trigger (unlike ScrollReveal which disconnects). It toggles both entering and leaving:

  ```html
  <script>
    // VIS-04: Background fade on scroll — toggles class (not one-shot like ScrollReveal)
    if (!window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
      const section = document.querySelector('[data-bg-fade]');
      if (section) {
        const observer = new IntersectionObserver((entries) => {
          entries.forEach(entry => {
            entry.target.classList.toggle('bg-visible', entry.isIntersecting);
          });
        }, { threshold: 0.1 });
        observer.observe(section);
      }
    }
  </script>
  ```

  **Important differences from ScrollReveal:**
  - ScrollReveal uses `obs.unobserve(entry.target)` — one-shot, disconnect after trigger
  - Background fade uses `classList.toggle()` — bidirectional, stays observing forever
  - Uses `threshold: 0.1` (10% visible triggers) vs ScrollReveal's `0.15`
  </action>
