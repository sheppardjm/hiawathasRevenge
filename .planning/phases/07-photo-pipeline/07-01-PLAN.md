<task type="auto">
  <name>Task 2: Create generate-thumbnails.js</name>
  <files>scripts/generate-thumbnails.js</files>
  <action>
    Create `scripts/generate-thumbnails.js` as an ESM module using top-level await.

    Follow the exact pattern from 07-RESEARCH.md "Complete generate-thumbnails.js" example:

    1. Import sharp (default export), fs (readdirSync, mkdirSync), path (join, extname, basename, dirname), url (fileURLToPath).
    2. Derive `__dirname` using `dirname(fileURLToPath(import.meta.url))`.
    3. Set `ROOT = join(__dirname, '..')`, `SRC_DIR = join(ROOT, 'images')`, `OUT_DIR = join(ROOT, 'public', 'thumbs')`.
    4. `mkdirSync(OUT_DIR, { recursive: true })` — create output dir if absent.
    5. Filter source files: `readdirSync(SRC_DIR).filter(f => extname(f).toLowerCase() === '.jpg')` — this naturally excludes the `inspiration/` subdirectory since readdirSync without recursion only returns top-level entries.
    6. For each source file in a `for...of` loop with `await`:
       - Derive thumbName: `basename(filename, extname(filename)).replace(/ /g, '_') + '.webp'`
       - Chain: `await sharp(srcPath).autoOrient().resize({ width: 400 }).webp({ quality: 80 }).toFile(outPath)`
       - Log each file: `thumbName (widthxheight, size bytes)`
    7. After loop, log summary: source count, generated count, output directory.

    Critical details:
    - `.autoOrient()` BEFORE `.resize()` — corrects EXIF rotation so portrait photos stay portrait.
    - `.resize({ width: 400 })` with only width — height auto-calculated to preserve aspect ratio.
    - `.webp({ quality: 80 })` — matches PHOTO-04 requirement exactly.
    - Sequential `await` in `for...of` is correct for a build script (no concurrency needed for 54 files).
    - Use top-level `await` (valid: project has `"type": "module"` in package.json, Node 25 supports it).
    - The `info` object returned by `.toFile()` contains `width`, `height`, `size` for logging.

    Add a JSDoc comment block at the top matching the style in resolve-annotations.js:
    ```

     * Reads source JPEG images from images/, generates 400px-wide WebP
     * thumbnails at 80% quality, and writes them to public/thumbs/.
     *
     * Usage: node scripts/generate-thumbnails.js
     */
    ```
