    ```javascript
    for (const sector of sectors) {
      const midIdx = Math.floor((sector.startIdx + sector.endIdx) / 2);
      const midPt = latlngs[midIdx];
      const bgColor = LABEL_COLORS[sector.difficulty] || LABEL_COLORS.moderate;
      const stars = '★'.repeat(sector.stars);

      const labelIcon = L.divIcon({
        className: 'sector-label',
        html: `<div style="
          background: ${bgColor};
          color: ${labelTextColor};
          border: 2px solid ${labelTextColor};
          border-radius: 12px;
          padding: 3px 8px;
          font-family: var(--font-display);
          font-size: 11px;
          font-weight: 700;
          white-space: nowrap;
          transform: translate(-50%, -50%);
          box-shadow: 2px 2px 0px rgba(0,0,0,0.4);
          line-height: 1.3;
          text-align: center;
        ">${sector.name}<br><span style="font-size: 9px; letter-spacing: 1px;">${stars}</span></div>`,
        iconSize: [0, 0],
        iconAnchor: [0, 0],
      });

      const labelMarker = L.marker(midPt, {
        icon: labelIcon,
        interactive: false,
        keyboard: false,
        zIndexOffset: 250,
      });

      sectorLabels.push(labelMarker);
    }
    ```

    IMPORTANT details:

    - Use `iconSize: [0, 0]` + `iconAnchor: [0, 0]` — variable-width text needs CSS centering, not fixed iconSize.
    - Set `interactive: false, keyboard: false` — labels must NOT intercept clicks (Phase 25 handles polyline clicks).
    - `zIndexOffset: 250` — above polylines, below restock (500), photo (750), bike (1000).
    - Do NOT add markers to map yet — zoom gating handles visibility.

    **3. Add zoom gating** — immediately after the label creation loop:

    ```javascript
    // Zoom gating — show sector labels at zoom >= 12, hide at lower zoom
    function updateLabelVisibility() {
      const zoom = map.getZoom();
      for (const marker of sectorLabels) {
        if (zoom >= 12 && !marker._map) {
          marker.addTo(map);
        } else if (zoom < 12 && marker._map) {
          marker.remove();
        }
      }
    }
    map.on('zoomend', updateLabelVisibility);
    // Initial check — labels may be visible at initial zoom level
    updateLabelVisibility();
    ```

    This uses the `marker._map` check pattern already established by the bikeMarker code (line 59). Labels are added/removed from the map rather than toggled via CSS — this is the Leaflet-idiomatic approach and avoids stale markers in the DOM.
