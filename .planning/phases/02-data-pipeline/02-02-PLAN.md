```javascript
const GRAVEL_SECTORS = [

  { id: "sector-rapid-river",name: "Rapid River Truck Trail",  startMile: 94.6, lengthMiles: 6.3 },

```

3. **Define restock points** as a hardcoded array:
```javascript
const RESTOCK_POINTS = [
  { id: "restock-camp7",    name: "Camp 7 Lake Campground",  mile: 44.7 },
  { id: "restock-midway",   name: "Midway General Store",    mile: 75.7 },
];
```

4. **Implement snapByMileage function**: Given a target mile value and the route points array, find the point with the minimum absolute difference in `miles`. Return the matched point's `lat`, `lon`, `ele`, `miles`, and the array index `snapIdx`.

5. **Snap gravel sectors**: For each sector, snap `startMile` to get `startLat`, `startLon`, `startIdx`. Compute `endMile = startMile + lengthMiles`. **Cap `endMile` at `meta.totalMiles` before snapping** (the last sector `rapid-river` has `endMile` of 100.9 which may exceed route length). Snap the capped `endMile` to get `endLat`, `endLon`, `endIdx`. **After snapping, if `endIdx <= startIdx`, clamp `endIdx = routePoints.length - 1`** to guarantee the verify check `startIdx < endIdx` passes. Build output entry:
```json
{
  "id": "sector-520",
  "type": "sector",
  "name": "520",
  "startMile": 1.1,
  "endMile": 2.4,
  "lengthMiles": 1.3,
  "startLat": 46.xxx,
  "startLon": -86.xxx,
  "endLat": 46.xxx,
  "endLon": -86.xxx,
  "startIdx": 12,
  "endIdx": 25
}
```

6. **Snap restock points**: For each restock point, snap the `mile` value. Build output entry:
```json
{
  "id": "restock-camp7",
  "type": "restock",
  "name": "Camp 7 Lake Campground",
  "mile": 44.7,
  "lat": 46.xxx,
  "lon": -86.xxx,
  "ele": 280.5,
  "snapIdx": 234
}
```

7. **Write output JSON** to `public/data/annotations.json` as a flat array combining all sectors and restock points:
```json
[
  { "id": "sector-520", "type": "sector", ... },
  { "id": "sector-nf2266", "type": "sector", ... },
  ...
  { "id": "restock-camp7", "type": "restock", ... },
  { "id": "restock-midway", "type": "restock", ... }
]
```

8. **Log summary to stdout**: Print count of sectors snapped, count of restock points snapped, and total gravel mileage (sum of all sector lengths).

Round lat/lon to 5 decimal places, miles to 2 decimal places.
