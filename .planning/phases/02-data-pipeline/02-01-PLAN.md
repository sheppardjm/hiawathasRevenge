<task type="auto">
  <name>Task 1: Install dependencies and write parse-gpx.js</name>
  <files>scripts/parse-gpx.js, package.json</files>
  <action>
Install dependencies:
```bash
PATH="/usr/local/opt/node/bin:$PATH" npm install @we-gold/gpxjs simplify-js
```

Create `scripts/parse-gpx.js` as an ESM module (`"type": "module"` is already in package.json). The script must:

1. **Read and parse GPX**: Read `Munising_Hiawatha_s_Revenge.gpx` from the project root using `fs.readFileSync`. Parse with `parseGPX` from `@we-gold/gpxjs`. Extract `parsed.tracks[0].points` — each point has `{ latitude, longitude, elevation }`.

2. **Compute cumulative mileage on FULL point set** (before simplification): Use haversine formula to compute distance between consecutive points. Accumulate as miles (divide meters by 1609.344). Store as `miles` property on each point.

3. **Apply RDP simplification** via `simplify-js`:
   - Map each point to `{ x: longitude, y: latitude }` and carry the original index via a custom `_i` property so you can reconstruct the full data after simplification.
   - Use `simplify(points, tolerance, true)` with `highQuality: true`.
   - Start with tolerance `0.0005` (decimal degrees). Aim for under 600 points from the original ~1927. If the first run produces too many or too few points, adjust tolerance. Log the point count to stdout.
   - After simplification, map back to the original point objects using the `_i` index to recover lat, lon, ele, and miles.
   - **IMPORTANT**: `simplify-js` is a CJS module. Try `import simplify from 'simplify-js'` first. If that fails (default export undefined), use `import { createRequire } from 'module'` and `const simplify = createRequire(import.meta.url)('simplify-js')`.

4. **Compute elevation gain with noise filter**: Iterate over the SIMPLIFIED point set. Use a threshold of 5 meters. Track a `lastEle` anchor. Only count upward deltas that exceed the threshold as gain. Reset anchor on any delta (up or down) exceeding the threshold. Print the computed gain in both meters and feet to stdout.

5. **Compute total distance**: Take the `miles` value of the last point in the simplified array.

6. **Write output JSON** to `public/data/route-data.json`:
```json
{
  "points": [
    { "lat": 46.xxx, "lon": -86.xxx, "ele": 280.5, "miles": 0.0 },
    ...
  ],
  "meta": {
    "totalMiles": 100.x,
    "elevationGainMeters": xxxx,
    "elevationGainFeet": xxxx,
    "pointCount": 5xx,
    "originalPointCount": 1927,
    "simplificationTolerance": 0.0005,
    "elevationThresholdMeters": 5
  }
}
```
Ensure `public/data/` directory is created with `mkdirSync({ recursive: true })` before writing.

Round lat/lon to 5 decimal places (~1m precision), ele to 1 decimal, miles to 2 decimals to keep file size small.
