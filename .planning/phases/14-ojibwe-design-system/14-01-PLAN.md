Create `src/components/FloralDivider.astro` — an inline SVG section divider inspired by Ojibwe woodland floral beadwork visual vocabulary.

**SVG structure (viewBox="0 0 800 60", width="100%", height="60"):**

The SVG should contain these motif elements, hand-authored as SVG paths/shapes:

1. **Central vine ("vine of life")** — A continuous curvilinear S-curve running the full 800px width at vertical center (y≈30). Use quadratic bezier curves (Q) to create gentle, organic undulation. Stroke: `var(--color-gold-500)`, stroke-width 1.5, fill none, opacity 0.7.

2. **Opposing leaf pairs** — At 3-4 inflection points along the vine (e.g., x=150, x=350, x=650), place pairs of teardrop-shaped leaves using `<ellipse>` elements rotated to oppose each other (one rotated -25°, one +25°). Fill: `var(--color-moss-500)`, opacity 0.5-0.6. Size: rx≈10, ry≈4.

3. **Five-petal blossoms** — At 2-3 points along the vine (e.g., x=250, x=550), create small five-petal flower forms. Each blossom is 5 small ellipses (rx≈4, ry≈2) arranged radially around a center point at 72° intervals (0°, 72°, 144°, 216°, 288°). Petals fill: `var(--color-gold-400)`, opacity 0.6. Center dot: `<circle>` r≈2, fill `var(--color-berry-600)`, opacity 0.7.

4. **Double-curve accents** (optional, at x≈400 center) — Two small opposing arcs meeting at a point, creating the characteristic Ojibwe double-curve motif. Stroke: `var(--color-gold-500)`, stroke-width 1, fill none, opacity 0.5.

**Component wrapper:**
```astro
<div class="floral-divider max-w-4xl mx-auto" aria-hidden="true" role="presentation">
  <svg ... aria-hidden="true" role="presentation" focusable="false">
    <!-- motifs here -->
  </svg>
</div>
```

The wrapper div uses `max-w-4xl mx-auto` to match the existing topo-divider width constraint. The `aria-hidden="true"`, `role="presentation"`, and `focusable="false"` attributes ensure the decorative SVG is invisible to screen readers.

**Design principles:**
- Keep motifs sparse and elegant — this is a subtle divider, not a dense border
- All colors reference Phase 12 CSS custom properties via `var(--color-*)` — no hardcoded hex values
- Match the 60px height of the existing topo-divider to preserve vertical rhythm
- Opacity values keep the decoration understated against the dark forest background
- Add a comment at the top of the component noting the Ojibwe woodland floral beadwork inspiration

**Do NOT:**
- Copy SVG files from external sources (Neebin Studios or others) — hand-author all paths
- Use CSS data-URI approach — inline SVG is required for CSS variable support
- Add any interactive behavior or animation to the SVG
