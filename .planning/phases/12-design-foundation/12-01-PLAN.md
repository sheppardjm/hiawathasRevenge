<task type="auto">
  <name>Task 1: Add new color token families with @theme static</name>
  <files>src/styles/global.css</files>
  <action>
Change `@theme {` to `@theme static {` on line 12 of global.css. This is REQUIRED so that all color tokens are output as CSS custom properties to :root, even tokens not used in any Tailwind utility class. Without `static`, getComputedStyle() in Phase 12 Plan 02 will return empty strings for tokens only referenced in JavaScript.

Add the following new color families AFTER the existing cream section and BEFORE the Typography Scale section. Include WCAG AA usage comments so future developers know which colors are safe for body text:

```css
  /* ============================================================
     v1.1: Ojibwe-inspired color families
     ============================================================ */

  /* Berry family — decorative/large-text only (fails AA normal text on dark bg) */
  --color-berry-700: #7a2e3d;
  --color-berry-600: #9a3a4f;
  --color-berry-500: #b34d63;

  /* Gold family — PASSES AA normal text on forest-900 and forest-950 */
  --color-gold-600: #b8860b;
  --color-gold-500: #d4a017;
  --color-gold-400: #e6b422;

  /* Lake family — lake-400 PASSES AA; lake-500/600/700 are decorative only */
  --color-lake-700: #2c5282;
  --color-lake-600: #2b6cb0;
  --color-lake-500: #3182ce;
  --color-lake-400: #4a9eca;

  /* Moss family — decorative/non-text only (fails AA on dark bg) */
  --color-moss-600: #6b7c3f;
  --color-moss-500: #7d9448;
```

Keep ALL existing tokens exactly as-is. Only change the `@theme` line and add the new block.
  </action>

<task type="auto">
  <name>Task 2: Remove BaseLayout width constraint and add per-section containers</name>
  <files>src/layouts/BaseLayout.astro, src/pages/index.astro</files>
  <action>
**BaseLayout.astro** — Change line 28 from:
```html
<main class="max-w-4xl mx-auto px-4 py-8">
```
to:
```html
<main>
```

This removes `max-w-4xl mx-auto px-4 py-8` entirely. The `<main>` element becomes unconstrained, allowing child sections to control their own width. This is the prerequisite for Phase 13's full-width hero.

**index.astro** — Add `max-w-4xl mx-auto px-4` to each section so the current visual appearance is preserved. The removed `py-8` from main was contributing top/bottom padding; existing sections already have their own `py-[--spacing-section]` or `py-[--spacing-block]` so this is already handled EXCEPT the first and last sections need to compensate.

Here is the exact class mapping for each section in index.astro. Apply these changes to the opening `<section>` or `<div>` tag of each content block:

1. Badge section (line 12): Change to `class="max-w-4xl mx-auto px-4 pt-8 py-[--spacing-section] flex flex-col items-center text-center"` — add `max-w-4xl mx-auto px-4 pt-8` (pt-8 compensates for removed main py-8)
2. DonateCallout section (line 53): Change to `class="max-w-4xl mx-auto px-4 py-[--spacing-block] flex justify-center"`
3. First topo-divider (line 57): Change to `class="topo-divider max-w-4xl mx-auto"` — add width constraint and centering
4. The Route section (line 59): Change to `class="max-w-4xl mx-auto px-4 py-[--spacing-block]"`
5. Route Stats section (line 96): Change to `class="max-w-4xl mx-auto px-4 py-[--spacing-block]"`
6. GPX download section (line 101): Change to `class="max-w-4xl mx-auto px-4 py-[--spacing-block] flex flex-col items-center gap-2"`
7. Second topo-divider (line 112): Change to `class="topo-divider max-w-4xl mx-auto"`
8. Explore the Route section (line 114): Change to `class="max-w-4xl mx-auto px-4 py-[--spacing-block]"` — keep the `id="route"`
9. Elevation Profile section (line 119): Change to `class="max-w-4xl mx-auto px-4 py-[--spacing-block]"`
10. Photos section (line 125): Change to `class="max-w-4xl mx-auto px-4 py-[--spacing-block]"`
11. Support the Trail section (line 129): Change to `class="max-w-4xl mx-auto px-4 py-[--spacing-block]"`

IMPORTANT: Do NOT change any other attributes on these elements (id, etc.). Only modify the class attribute.
