    Create `src/components/RouteStats.astro` that queries route data and annotations at build time.

    **Frontmatter:**

    ```astro
    ---
    import { getEntry, getCollection } from 'astro:content';

    const routeEntry = await getEntry('routeData', 'route');
    const { totalMiles, elevationGainFeet } = routeEntry!.data.meta;

    const allAnnotations = await getCollection('annotations');
    const sectors = allAnnotations.filter(a => a.data.type === 'sector');
    const easyMiles = sectors
      .filter(s => s.data.type === 'sector' && s.data.difficulty === 'easy')
      .reduce((n, s) => n + (s.data.type === 'sector' ? s.data.lengthMiles : 0), 0);
    const moderateMiles = sectors
      .filter(s => s.data.type === 'sector' && s.data.difficulty === 'moderate')
      .reduce((n, s) => n + (s.data.type === 'sector' ? s.data.lengthMiles : 0), 0);
    const hardMiles = sectors
      .filter(s => s.data.type === 'sector' && s.data.difficulty === 'hard')
      .reduce((n, s) => n + (s.data.type === 'sector' ? s.data.lengthMiles : 0), 0);
    const roadMiles = Math.round((totalMiles - easyMiles - moderateMiles - hardMiles) * 10) / 10;
    ---
    ```

    IMPORTANT: The annotations collection uses a discriminated union — `s.data.difficulty` only exists on entries where `s.data.type === 'sector'`. The filter to `sectors` already ensures this, but TypeScript may still require the type guard. If the type narrowing does not compile, use type assertion: `(s.data as any).difficulty` or filter with an explicit type check.
