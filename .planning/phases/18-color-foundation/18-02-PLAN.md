  **Step 3: Create `scripts/process-historical.js`** — a standalone pipeline script modeled on `generate-thumbnails.js` + `match-photos.js`.

  The script must:

  1. Use ES module imports (matching existing scripts): `sharp`, `fs` (readdirSync, mkdirSync, existsSync, copyFileSync, readFileSync, writeFileSync), `path`, `url`.

  2. Define paths:
     - `SRC_DIR`: `images/historical/` (source historical images)
     - `OUT_THUMBS`: `public/thumbs/historical/` (WebP thumbnails)
     - `OUT_IMAGES`: `public/images/historical/` (full-res copies)
     - `MANIFEST_PATH`: `public/data/historical-manifest.json` (input manifest)
     - `OUTPUT_PATH`: `public/data/historical-photos.json` (output data file)

  3. Implement **graceful absent-manifest guard** (same pattern as match-photos.js):
     ```javascript
     if (!existsSync(MANIFEST_PATH)) {
       console.warn('process-historical: historical-manifest.json not found — writing empty output');
       mkdirSync(dirname(OUTPUT_PATH), { recursive: true });
       writeFileSync(OUTPUT_PATH, '[]', 'utf8');
       process.exit(0);
     }
     ```

  4. Implement **graceful absent-source-dir guard**:
     ```javascript
     if (!existsSync(SRC_DIR)) {
       mkdirSync(SRC_DIR, { recursive: true });
       console.warn('process-historical: images/historical/ not found — created, writing empty output');
       writeFileSync(OUTPUT_PATH, '[]', 'utf8');
       process.exit(0);
     }
     ```

  5. Create output directories with `mkdirSync({ recursive: true })`.

  6. Read and parse the manifest JSON. Filter for `SUPPORTED_EXTS`: `.jpg`, `.jpeg`, `.png`, `.tiff`, `.tif`, `.webp`.

  7. For each manifest entry:
     - Skip if `entry.category !== 'historical'` (log warning).
     - Skip if `entry.filename` not found in source directory (log warning).
     - Process with sharp: `.autoOrient().resize({ width: 400 }).webp({ quality: 80 }).toFile(thumbPath)` — identical to generate-thumbnails.js.
     - Copy full-res source to `OUT_IMAGES`.
     - Build result object with fields: `filename`, `category`, `thumb`, `title`, `artist`, `year`, `source`, `license`.
     - Log: `thumbName (widthxheight, bytes)`.

  8. Write results array to `OUTPUT_PATH` as JSON with 2-space indent.

  9. Log summary: `process-historical: complete — N images processed`.

  10. Handle the case of an empty manifest `[]` gracefully — the loop simply produces zero results and writes `[]` to output. Do NOT special-case empty arrays.

  **Important:** Use `await` for sharp calls (top-level await, matching generate-thumbnails.js pattern). Do NOT wrap in async function — the existing scripts use top-level await in ES modules.

  Full reference implementation is provided in 18-RESEARCH.md "Code Examples > process-historical.js Structure" section — follow that structure exactly.
