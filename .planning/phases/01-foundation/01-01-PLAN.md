<task type="auto">
  <name>Task 1: Scaffold Astro 6 project with Tailwind 4, Vite 7 override, and TypeScript strict</name>
  <files>package.json, astro.config.ts, tsconfig.json, src/env.d.ts</files>
  <action>
    Create the Astro project manually (do NOT use `create astro` wizard -- it generates unwanted boilerplate and may not pick the right versions).

    1. Create `package.json` with:
       - name: "hiawathas-revenge"
       - type: "module"
       - scripts: { "dev": "astro dev", "build": "astro build", "preview": "astro preview" }
       - dependencies: { "astro": "^6.1.1" }
       - devDependencies: { "@tailwindcss/vite": "^4.2.2", "tailwindcss": "^4.2.2" }
       - overrides: { "vite": "^7" }
       (The Vite 7 override is REQUIRED -- Astro 6 ships with Vite 6 but Tailwind 4.2+ needs Vite 7. Without this override, Tailwind styles will not resolve.)

    2. Create `astro.config.ts`:
       ```ts
       import { defineConfig } from 'astro/config';
       import tailwindcss from '@tailwindcss/vite';

       export default defineConfig({
         output: 'static',
         vite: {
           plugins: [tailwindcss()],
         },
       });
       ```
       (Use `output: 'static'` explicitly -- this is required by BUILD-08. Do NOT add `server` or `hybrid` output modes.)

    3. Create `tsconfig.json`:
       ```json
       {
         "extends": "astro/tsconfigs/strict"
       }
       ```
       (Use "strict" not "base" -- the project decision is TypeScript strict mode.)

    4. Create `src/env.d.ts`:
       ```ts
       /// <reference types="astro/client" />
       ```

    5. Run `npm install` from the project root.

    6. Verify `npm run dev` starts without errors (run briefly, confirm it starts, then stop).

    7. Verify `npm run build` completes and creates `dist/` directory.
  </action>
  <verify>
    - `npm run dev` starts and serves at localhost (check for "Local" URL in output)
    - `npm run build` completes without errors
    - `ls dist/` shows output files
    - `cat package.json | grep '"vite"'` shows the ^7 override
    - `cat astro.config.ts | grep 'static'` confirms output mode
  </verify>
  <done>
    Astro dev server starts clean, astro build produces static dist/ output, all dependencies installed at correct versions (Astro 6.x, Tailwind 4.x, Vite 7.x).
  </done>

<task type="auto">
  <name>Task 2: Define Forest Service design tokens in global.css @theme</name>
  <files>src/styles/global.css</files>
  <action>
    Create `src/styles/global.css` with the complete Forest Service / National Park design token system using Tailwind 4 CSS-first configuration.

    IMPORTANT: Tailwind 4 uses `@theme` blocks in CSS instead of `tailwind.config.js`. Do NOT create a tailwind.config.js or tailwind.config.ts file -- it will conflict with the CSS-first approach.

    The file must contain:

    1. Tailwind import at the top:
       ```css
       @import "tailwindcss";
       ```

    2. A `@theme` block defining ALL custom design tokens as CSS custom properties. These become available as Tailwind utilities (e.g., `bg-forest-900` resolves to `--color-forest-900`).

    Color palette (Forest Service / National Park identity):
    - `--color-forest-950`: #0d1a0d (darkest green, near-black for deep backgrounds)
    - `--color-forest-900`: #1a2e1a (primary dark forest green -- main background)
    - `--color-forest-800`: #2d4a2d (slightly lighter green for cards/panels)
    - `--color-forest-700`: #3d6b3d (medium green for borders/accents)
    - `--color-forest-600`: #4a8a4a (brighter green for hover states)
    - `--color-amber-500`: #c8973e (primary warm amber/gold -- headings, accents, CTAs)
    - `--color-amber-400`: #d4a84e (lighter amber for hover states)
    - `--color-amber-300`: #e0b95f (lightest amber for subtle highlights)
    - `--color-rust-600`: #8b4513 (rust/terracotta accent for badges/borders)
    - `--color-rust-500`: #a0522d (lighter rust for decorative elements)
    - `--color-cream-100`: #f5f0e8 (primary text color -- cream/parchment)
    - `--color-cream-200`: #e8e0d0 (secondary text -- slightly warmer)
    - `--color-cream-50`: #faf8f4 (lightest cream for highlights)

    Typography scale (using rem, body base 1rem = 16px):
    - `--font-size-xs`: 0.75rem
    - `--font-size-sm`: 0.875rem
    - `--font-size-base`: 1rem
    - `--font-size-lg`: 1.125rem
    - `--font-size-xl`: 1.25rem
    - `--font-size-2xl`: 1.5rem
    - `--font-size-3xl`: 1.875rem
    - `--font-size-4xl`: 2.25rem
    - `--font-size-5xl`: 3rem

    Font families (will be loaded by Astro Fonts API in BaseLayout):
    - `--font-mono`: 'Space Mono', ui-monospace, monospace
    - `--font-display`: 'Special Elite', cursive

    Spacing scale (for consistent gaps/padding):
    - `--spacing-section`: 4rem (space between major page sections)
    - `--spacing-block`: 2rem (space between content blocks within a section)
    - `--spacing-element`: 1rem (space between elements within a block)

    Shadow values (heavy badge-style shadows for the ranger station aesthetic):
    - `--shadow-badge`: 4px 4px 0px rgba(0, 0, 0, 0.5) (hard offset shadow for badge elements)
    - `--shadow-card`: 0 4px 12px rgba(0, 0, 0, 0.3) (softer shadow for cards/panels)
    - `--shadow-text`: 2px 2px 0px rgba(0, 0, 0, 0.7) (text shadow for heading legibility)

    Border values:
    - `--border-badge`: 3px solid var(--color-amber-500) (bold badge-style border)
    - `--border-subtle`: 1px solid var(--color-forest-700) (subtle divider)

    3. A `@layer base` block with foundational styles:
       ```css
       @layer base {
         html {
           background-color: var(--color-forest-900);
           color: var(--color-cream-100);
           font-family: var(--font-mono);
           line-height: 1.6;
         }

         h1, h2, h3, h4 {
           font-family: var(--font-display);
           color: var(--color-amber-500);
           text-shadow: var(--shadow-text);
         }

         a {
           color: var(--color-amber-400);
           text-decoration-color: var(--color-forest-700);
         }

         a:hover {
           color: var(--color-amber-300);
         }
       }
       ```

    4. Reserve a `@layer leaflet` block (empty for now) -- this will be used in Phase 3 to import Leaflet CSS without Tailwind's reset clobbering map controls:
       ```css
       @layer leaflet {
         /* Leaflet CSS will be imported here in Phase 3 */
       }
       ```
  </action>
