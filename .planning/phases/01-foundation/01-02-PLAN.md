  <name>Task 1: Create BaseLayout.astro with HTML shell, Astro Fonts API, and global styles</name>
  <files>src/layouts/BaseLayout.astro, astro.config.ts</files>
  <action>
    Create the base layout that every page will use. This layout provides the HTML shell, font loading, global CSS, and a consistent page wrapper.

    1. Configure Astro Fonts API in `astro.config.ts`:

       Update `astro.config.ts` to add the fonts integration. Astro 6 provides a built-in Fonts API via `fontProviders.google()` that self-hosts Google Fonts automatically (no external requests, no layout shift).

       ```ts
       import { defineConfig, fontProviders } from 'astro/config';
       import tailwindcss from '@tailwindcss/vite';

       export default defineConfig({
         output: 'static',
         experimental: {
           fonts: true,
         },
         fonts: {
           providers: [fontProviders.google()],
           families: [
             {
               name: 'Space Mono',
               provider: 'google',
               weights: [400, 700],
               styles: ['normal', 'italic'],
             },
             {
               name: 'Special Elite',
               provider: 'google',
               weights: [400],
               styles: ['normal'],
             },
           ],
         },
         vite: {
           plugins: [tailwindcss()],
         },
       });
       ```

       NOTE: If the `experimental.fonts` flag or the `fonts` config shape has changed in Astro 6.1.x, check the Astro docs. The key requirement is: Space Mono (400, 700) and Special Elite (400) must be self-hosted and injected into the page head automatically. If the Fonts API approach fails for any reason, fall back to manually adding `<link>` preload tags for the Google Fonts URLs in the layout head, with `font-display: swap` to prevent layout shift.

    2. Create `src/layouts/BaseLayout.astro`:

       ```astro
       ---
       interface Props {
         title: string;
         description?: string;
       }

       const { title, description = "A 100-mile cycling showcase through Michigan's Hiawatha National Forest" } = Astro.props;

       import '../styles/global.css';
       ---

       <!doctype html>
       <html lang="en">
         <head>
           <meta charset="utf-8" />
           <meta name="viewport" content="width=device-width, initial-scale=1" />
           <meta name="description" content={description} />
           <link rel="icon" type="image/svg+xml" href="/favicon.svg" />
           <title>{title}</title>
         </head>
         <body class="min-h-screen bg-forest-900 text-cream-100 font-mono">
           <main class="max-w-4xl mx-auto px-4 py-8">
             <slot />
           </main>
         </body>
       </html>
       ```

       Key points:
       - Import `global.css` in the frontmatter (this is how Astro processes CSS imports -- it injects the styles into the page head)
       - Use Tailwind utility classes that reference our @theme tokens: `bg-forest-900`, `text-cream-100`, `font-mono`
       - The `<slot />` is where page content renders
       - `max-w-4xl mx-auto` provides a centered content column (this is a simple starting layout -- Phase 10 will refine it)
       - Props accept `title` (required) and `description` (optional with sensible default)
       - Do NOT add a `<header>` or `<nav>` yet -- those come in Phase 10 with the badge h1

    3. Create a simple `public/favicon.svg` (forest-themed):
       ```svg
       <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 32 32">
         <text x="4" y="26" font-size="28">🌲</text>
       </svg>
       ```
