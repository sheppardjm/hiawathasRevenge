  - Do NOT add the class to the vine path. Only the berry circles get it.

  **Change 2: Add @keyframes and animation rules to the `<style>` block**

  Add these rules to the existing `<style>` block, AFTER the `.animated-divider.is-visible .vine-path` rule and BEFORE the `@media (prefers-reduced-motion)` rule:

  ```css
  /* Blossom petal color cycling — gold -> berry -> turquoise -> sun -> gold */
  @keyframes cycle-blossom {
    0%, 100% { fill: var(--color-gold-400); }
    25%      { fill: var(--color-berry-500); }
    50%      { fill: var(--color-turquoise-400); }
    75%      { fill: var(--color-sun-400); }
  }

  /* Berry circle color cycling — berry-500 -> berry-600 -> scarlet-400 -> berry-700 -> berry-500 */
  @keyframes cycle-berry {
    0%, 100% { fill: var(--color-berry-500); }
    25%      { fill: var(--color-berry-600); }
    50%      { fill: var(--color-scarlet-400); }
    75%      { fill: var(--color-berry-700); }
  }

  .blossom-cycle {
    animation: cycle-blossom 8s ease-in-out infinite;
  }

  .berry-cycle {
    animation: cycle-berry 6s ease-in-out infinite;
  }
  ```

  **Change 3: Add animation: none to the prefers-reduced-motion block**

  In the existing `@media (prefers-reduced-motion: reduce)` block, add rules to disable the color cycling:

  ```css
  @media (prefers-reduced-motion: reduce) {
    .vine-path {
      stroke-dashoffset: 0;
      transition: none;
    }
    .blossom-cycle,
    .berry-cycle {
      animation: none;
    }
  }
  ```

  **Critical details:**
  - The @keyframes use only token values already present in global.css — no new tokens needed
  - gold-400, berry-500, turquoise-400, sun-400 are all decorative-safe colors (these are fill values on decorative SVG elements, not text)
  - scarlet-400 is used in berry cycling (not scarlet-600, which is large-text-only per Phase 18-01 decision)
  - Animation durations (8s blossom, 6s berry) are intentionally different so the two variant types don't synchronize — this creates a more organic, less mechanical feel
  - `ease-in-out` timing function for smooth color transitions
  - `infinite` iteration count — cycles continuously while visible
  - The cycling only applies to decorative elements (already covered by the parent div's aria-hidden="true")
  - prefers-reduced-motion: reduce disables ALL animations including these new ones
  - Do NOT change any other part of the component — vine paths, leaves, center dots, double-curves, script block all remain exactly as they are
