   * Reads public/data/route-data.json and public/data/annotations.json,

   * to public/data/sector-elevations.json.

  **Logic:**
  1. Read `public/data/route-data.json` and parse JSON
  2. Read `public/data/annotations.json` and parse JSON
  3. Filter annotations to type === 'sector' only
  4. For each sector, using its `startIdx` and `endIdx`:
     - Slice `routeData.points` from `startIdx` to `endIdx + 1`
     - Extract elevation values and compute: eleMin, eleMax, eleGainMeters (sum of positive deltas), eleLossMeters (sum of negative deltas as positive number)
     - Build the output record:
       ```json
       {
         "id": "sector-nf2266",
         "name": "NF2266",
         "difficulty": "moderate",
         "startMile": 6.7,
         "endMile": 9.9,
         "elevationPoints": [
           { "miles": 6.72, "ele": 290.9 },
           ...
         ],
         "eleMin": 270.5,
         "eleMax": 290.9,
         "eleGainMeters": 9,
         "eleLossMeters": 28
       }
       ```
  5. Write results array to `public/data/sector-elevations.json` with `JSON.stringify(results, null, 2)`
  6. Log summary: number of sectors, total elevation points

  **Rounding:** Use `Math.round(value * 10) / 10` for eleMin/eleMax (1 decimal). Use `Math.round()` for eleGain/eleLoss (integers).

  **Edge case:** If annotations.json has no sectors (empty filter result), write `[]` and exit 0. Do NOT error — this matches the Phase 18 "empty manifest exits 0" pattern.

  **Part B: Create `src/components/ElevationSparkline.astro`**

  Create a new Astro component that reads the sectorElevations collection at build time and renders a static SVG polyline for a given sector.

  **Frontmatter:**
  ```astro
  ---
  // ElevationSparkline.astro
  // Renders a static SVG polyline showing a sector's elevation profile.
  // All data resolved at build time via content collection — zero client-side JavaScript.
  import { getCollection } from 'astro:content';

  interface Props {
    sectorId: string;
    class?: string;
  }
  const { sectorId, class: className = '' } = Astro.props;

  const allSectors = await getCollection('sectorElevations');
  const sector = allSectors.find(s => s.id === sectorId);

  let polylinePoints = '';
  let strokeColor = 'var(--color-gold-500)';

  if (sector) {
    const points = sector.data.elevationPoints;
    const eles = points.map(p => p.ele);
    const miles = points.map(p => p.miles);
    const eleMin = Math.min(...eles);
    const eleMax = Math.max(...eles);
    const eleRange = eleMax - eleMin;
    const milesRange = miles[miles.length - 1] - miles[0];

    const W = 100, H = 30;
    polylinePoints = points.map((p, i) => {
      const x = milesRange > 0
        ? (p.miles - miles[0]) / milesRange * W
        : i / Math.max(points.length - 1, 1) * W;
      const y = eleRange > 0
        ? H - ((p.ele - eleMin) / eleRange * H)
        : H / 2;
      return `${x.toFixed(1)},${y.toFixed(1)}`;
    }).join(' ');

    const DIFFICULTY_COLORS = {
      easy:     'var(--color-moss-500)',
      moderate: 'var(--color-gold-500)',
      hard:     'var(--color-scarlet-400)',
    };
    strokeColor = DIFFICULTY_COLORS[sector.data.difficulty] ?? 'var(--color-gold-500)';
  }
  ---
  ```

  **Template:** Only render if sector was found and polylinePoints is non-empty:
  ```html
  {polylinePoints && (
    <svg
      viewBox="0 0 100 30"
      width="100%"
      height="30"
      class={className}
      aria-hidden="true"
      role="presentation"
      focusable="false"
    >
      <polyline
        points={polylinePoints}
        stroke={strokeColor}
        stroke-width="1.5"
        fill="none"
        stroke-linejoin="round"
        stroke-linecap="round"
      />
    </svg>
  )}
  ```

  **Critical details:**
  - Zero `<script>` block — this is purely build-time rendered
  - Uses `getCollection('sectorElevations')` to read from the content collection (NOT a direct JSON import from public/)
  - Stroke color is difficulty-coded: easy=moss-500, moderate=gold-500, hard=scarlet-400 (scarlet-400 is text-safe at 5.24:1, NOT scarlet-600 which is large-text-only)
  - viewBox is "0 0 100 30" — sparkline aspect ratio optimized for inline display
  - stroke-linejoin="round" and stroke-linecap="round" for smooth appearance
  - Renders nothing if sector not found (graceful degradation)
  - `class` prop passed through for external positioning/styling
  - Decorative: aria-hidden="true", role="presentation", focusable="false"
