  - Vine shadow path (offset +2 on y): same shape with `stroke="var(--color-berry-700)"`, `stroke-width="1"`, `opacity="0.3"`, `pathLength="1"`, class="vine-path"
  - Three leaf pairs at x=150, x=400, x=650 using `<ellipse>` elements (from FloralDivider). These are NOT animated (no vine-path class) — they appear immediately. Use colors: moss-500 fills with lake-500, lake-600, turquoise-500, sun-500 strokes as in FloralDivider.
  - Two five-petal blossoms at x=270 and x=530 (from FloralDivider). NOT animated — visible immediately. gold-400 petals, berry-500/berry-600 center dots, lake-700 background circles.
  - Double-curve accents at x=400: gold-600 upper, gold-500 lower. NOT animated.
  - Accent dot: `<circle cx="400" cy="30" r="1.5" fill="var(--color-scarlet-400)" opacity="0.5" />`

  **variant="minimal":** Lighter SVG for minor section breaks:
  - viewBox="0 0 800 30", width="100%", height="30"
  - Upper curve: `d="M200 15 Q400 5 600 15"` with `pathLength="1"`, `stroke="var(--color-gold-600)"`, `stroke-width="1"`, `fill="none"`, class="vine-path"
  - Lower curve: `d="M200 15 Q400 25 600 15"` with `pathLength="1"`, `stroke="var(--color-gold-500)"`, `stroke-width="1"`, `fill="none"`, `opacity="0.5"`, class="vine-path"

  **variant="berry":** Intermediate complexity:
  - viewBox="0 0 800 40", width="100%", height="40"
  - Vine curve: `d="M100 20 Q250 8 400 20 Q550 32 700 20"` with `pathLength="1"`, `stroke="var(--color-berry-500)"`, `stroke-width="1.5"`, `fill="none"`, class="vine-path"
  - 3 berry cluster circles at x=250, x=400, x=550 (groups of 3 small circles each, r=2-3, fills of berry-500, berry-600, berry-700 at varying opacities). NOT animated.

  **Style block:** Scoped `<style>` containing:
  ```css
  .animated-divider {
    max-width: 56rem;
    margin: 0 auto;
  }

  .vine-path {
    stroke-dasharray: 1;
    stroke-dashoffset: 1;
    transition: stroke-dashoffset 1.4s cubic-bezier(0.4, 0, 0.2, 1);
  }

  .animated-divider.is-visible .vine-path {
    stroke-dashoffset: 0;
  }

  @media (prefers-reduced-motion: reduce) {
    .vine-path {
      stroke-dashoffset: 0;
      transition: none;
    }
  }
  ```

  **Script block:** `<script>` using the same IntersectionObserver pattern as ElevationProfile.astro:
  ```javascript
  document.querySelectorAll('.animated-divider').forEach((divider) => {
    const observer = new IntersectionObserver(
      (entries) => {
        if (entries[0].isIntersecting) {
          divider.classList.add('is-visible');
          observer.disconnect();
        }
      },
      { threshold: 0.3 }
    );
    observer.observe(divider);
  });
  ```

  **Critical implementation details:**
  - ALL animated `<path>` elements MUST have `pathLength="1"` — this normalizes stroke-dashoffset to work without getTotalLength()
  - Use `querySelectorAll` (not `querySelector`) to support multiple instances on the same page
  - Static elements (leaves, blossoms, berry clusters, accent dots) do NOT get the `vine-path` class — they appear immediately
  - Only vine/curve paths that should draw on get the `vine-path` class
  - The `@media (prefers-reduced-motion: reduce)` block sets `stroke-dashoffset: 0` and `transition: none` so the vine is visible statically with no animation
  - The component is purely decorative: `aria-hidden="true"` and `role="presentation"` on both the wrapper div and the SVG elements
