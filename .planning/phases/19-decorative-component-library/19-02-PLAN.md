  <action>
  Create `src/components/ShieldMotif.astro` as a reusable component that emits an `<svg>` with a `<use href="#shield-motif">` reference to the symbol defined in BaseLayout.

  **Frontmatter:**
  ```astro
  ---
  // ShieldMotif.astro
  // Renders the shield/arrowhead motif at any size via SVG <use>.
  // Symbol definition lives in BaseLayout.astro.
  // Color inherits from parent via currentColor — use Tailwind text-* classes.
  interface Props {
    size?: number;
    class?: string;
    label?: string;
  }
  const { size = 24, class: className = '', label } = Astro.props;
  const isDecorative = !label;
  const height = size * 2; // Shield aspect ratio is 1:2 (28 wide x 56 tall)
  ---
  ```

  **Template:**
  ```html
  <svg
    width={size}
    height={height}
    class={className}
    aria-hidden={isDecorative ? 'true' : undefined}
    aria-label={!isDecorative ? label : undefined}
    role={isDecorative ? 'presentation' : 'img'}
    focusable="false"
  >
    <use href="#shield-motif" />
  </svg>
  ```

  **Usage examples (for documentation in the component comment, not to implement):**
  - Icon: `<ShieldMotif size={20} class="text-amber-500" />`
  - Watermark: `<ShieldMotif size={500} class="text-gold-600 opacity-[0.04] absolute" />`
  - Accessible: `<ShieldMotif size={24} class="text-amber-400" label="Shield emblem" />`

  **Critical details:**
  - No `<style>` block needed — all styling via Tailwind classes passed through `class` prop
  - No `<script>` block needed — purely server-rendered, zero client-side JS
  - The `height` is always `size * 2` to maintain the 1:2 aspect ratio of the 28x56 viewBox
  - When `label` is provided, `aria-hidden` is omitted and `aria-label` + `role="img"` are set
  - When `label` is omitted (decorative), `aria-hidden="true"` and `role="presentation"` are set
  - The `<use>` element references `#shield-motif` which must be defined in the same HTML document (guaranteed by BaseLayout.astro)
