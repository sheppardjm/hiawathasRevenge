## Decisions Made
- Panel close check inserted at step 1.5 (after Promise.all, before clearActiveRoute) — ordering is critical: clearActiveRoute() nulls activeSector, making any check after it dead code
- keepPanelSectorId captures sector ID string (not object reference) before clearActiveRoute(), then restored to activeSector after sector overlay rebuild loop (step 5.5)
- Legacy root-level JSON files (public/data/annotations.json, sector-elevations.json) not regenerated by pipeline — updated manually for consistency
- route-config.js SECTOR_DEFS is the canonical name source; pipeline propagates to all JSON outputs
