After the `await Promise.all(...)` block and before `clearActiveRoute()`, insert:

```javascript
// 1.5. Panel close-on-switch — MUST run before clearActiveRoute() nulls activeSector
// Close the panel if the open sector is not on the NEW route being loaded
const newRouteConfig = routesManifest.routes.find(r => r.id === routeId);
```

**IMPORTANT:** Use `routeId` (the incoming route parameter), NOT `activeRouteId` (the currently displayed route). The intent is: "if the sector that is open is not present on the new route, close the panel."

