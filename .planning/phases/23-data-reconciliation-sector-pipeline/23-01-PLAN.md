  <name>Task 2: Create generate-surface-points.js and wire into pipeline</name>
  <files>scripts/generate-surface-points.js, scripts/pipeline.js</files>
  <action>
    **Create scripts/generate-surface-points.js:**

    Follow the exact existing pipeline script pattern (ESM imports, __dirname via fileURLToPath, readFileSync/writeFileSync, summary logging).

    1. Define S_TO_SURFACE mapping constant:
       - S=95 -> "paved"
       - S=56 -> "gravel"
       - S=57 -> "gravel" (compacted/fine gravel, treat same as gravel)
       - S=59 -> "dirt"
       - S=0 -> "unknown"

    2. Load two input files:
       - `public/data/route-data.json` (simplified 456 points — has .points array with lat, lon, miles)
       - `hiawathasRevenge.json` (RidewithGPS export — has .route.track_points array with x=lon, y=lat, S=surface integer)

    3. Build coordinate lookup Map from original track_points:
       - Key: `"${Math.round(op.y * 100000) / 100000},${Math.round(op.x * 100000) / 100000}"` (y=lat, x=lon, rounded to 5 decimals)
       - Value: op.S (surface integer)
       - Only store first occurrence per key (use `if (!origLookup.has(key))`)

    4. Map simplified points to surface types:
       - For each simplified point, build key as `"${sp.lat},${sp.lon}"` (already 5-decimal in route-data.json)
       - Look up S value from origLookup
       - Output: `{ miles: sp.miles, surface: S_TO_SURFACE[sValue] ?? 'unknown' }`
       - Track matched/unmatched counts

    5. Write output to `public/data/surface-points.json` (JSON.stringify with 2-space indent)

    6. Log summary: script name, points matched count, unmatched count, output path

    7. Fail with process.exit(1) if unmatched > 5 (should be 0, this is a safety guard)

    **In scripts/pipeline.js:**

    8. Insert `{ name: 'generate-surface-points', script: 'scripts/generate-surface-points.js' }` into the steps array AFTER `parse-gpx` and BEFORE `resolve-annotations`. This is the correct position because generate-surface-points reads route-data.json (produced by parse-gpx) but does not depend on annotations.json.

    See 23-RESEARCH.md "Code Examples > DATA-03" section for the full reference implementation.
