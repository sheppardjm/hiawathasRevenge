  <files>src/styles/global.css, src/components/RouteMap.astro, src/pages/index.astro</files>
  <action>
1. In `src/styles/global.css`, inside the `@layer base { }` block, add a global `:focus-visible` rule AFTER the existing `a:hover` rule (around line 160). Add:


2. In `src/components/RouteMap.astro`, in the `<style>` block, add a `:focus-visible` rule for the panel close button AFTER the existing `.sector-panel__close:hover` rule (after line 127):

```css
.sector-panel__close:focus-visible {
  outline: 2px solid var(--color-amber-500);
  outline-offset: 2px;
  border-radius: 2px;
  opacity: 1;
}
```

Also add `:focus-visible` styles for the innerHTML-injected panel links. These are NOT Astro-scoped (they're injected via innerHTML in openPanel()), so they inherit the global baseline from global.css. No additional component styles needed for `.panel-strava-link` or `.panel-jump-link`.

3. In `src/pages/index.astro`, in the `<style>` block, add a gold-section focus override AFTER the existing `.gold-section :global(a)` rule (after line 146). The amber focus ring would be invisible on the sun-500 background, so override to forest-950:

```css
.gold-section :global(a:focus-visible),
.gold-section :global(button:focus-visible) {
  outline-color: var(--color-forest-950);
}
```

Important:
- Use `:focus-visible` NOT `:focus` — keyboard-only, mouse clicks should NOT show the ring.
- The global baseline in `@layer base` ensures even innerHTML-injected elements (panel links, sparkline SVGs) get focus styling.
- Do NOT change the `outline` shorthand in the gold-section override — only override `outline-color` so the width and offset from the global rule are preserved.
