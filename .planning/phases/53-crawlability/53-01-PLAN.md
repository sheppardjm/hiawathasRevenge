  <name>Task 1: Install @astrojs/sitemap and configure Astro integration with path filter</name>
  <files>
    package.json
    astro.config.ts
  </files>
  <action>
    **Step A: Install @astrojs/sitemap**
    Run `npm install @astrojs/sitemap` to add the official Astro sitemap integration as a dependency.

    **Step B: Update astro.config.ts**
    Add the sitemap integration to `astro.config.ts`:

    1. Add import at the top of the file: `import sitemap from '@astrojs/sitemap';`
    2. Add an `integrations` array to the `defineConfig` object with the sitemap integration configured with a `filter` callback:

    ```typescript
    integrations: [
      sitemap({
        filter: (page) =>
          !page.includes('/admin') &&
          !page.includes('/api/'),
      }),
    ],
    ```

    Place the `integrations` array after the `output` property and before the `fonts` property.

    **IMPORTANT anti-patterns to avoid:**
    - Do NOT set `changefreq` or `priority` -- Google ignores both fields.
    - Do NOT change the existing `site`, `output`, `fonts`, or `vite` configuration.
    - The `site` property (`https://hiawathasrevenge.com`) is already set -- do not duplicate it.

    **Step C: Verify installation**
    Run `node -e "require('@astrojs/sitemap')"` (or equivalent) to confirm the package resolves.
  </action>
  <verify>
    - `grep '@astrojs/sitemap' package.json` shows the dependency
    - `grep 'sitemap' astro.config.ts` shows the import and integration
    - `grep 'filter' astro.config.ts` shows the admin/api exclusion filter
  </verify>
  <done>
    @astrojs/sitemap installed and configured in astro.config.ts with a filter excluding /admin and /api/ paths from sitemap output.
  </done>
</task>

    **Step A: Create public/robots.txt**
    Create a plain text file at `public/robots.txt` with the following exact content:

    ```

    Disallow: /api/

    Sitemap: https://hiawathasrevenge.com/sitemap-index.xml
    ```

    - The `Sitemap:` directive MUST use the full absolute URL with `https://`.
    - The sitemap filename MUST be `sitemap-index.xml` (not `sitemap.xml`) -- this is what `@astrojs/sitemap` generates.
    - Each directive is on its own line. One blank line separates the Allow block from the Disallow block, and one blank line before the Sitemap directive.

    **Step B: Run full build**
    Run `npm run build` using the project's Node (Volta: `/Users/Sheppardjm/.volta/bin/node`). Verify:

    5. `dist/sitemap-0.xml` does NOT contain `/admin` or `/api/`
