**Template structure:**

The component is a full-width `<section>` with topo background, containing a `max-w-4xl mx-auto px-4` inner container:

```html
<section class="route-explainer-section py-[--spacing-block]">
  <div class="max-w-4xl mx-auto px-4">
    <h2 class="text-3xl mb-[--spacing-element]">The Route, Segment by Segment</h2>
    <p class="max-w-prose text-cream-200 mb-8">
      Brief intro text — something like "100 miles of forest roads, two-track, and singletrack. Seven segments, each with its own character. Here's what to expect."
    </p>
    {segmentsWithPhotos.map((seg, i) => (
      <article class={`segment-card ${seg.photos.length === 0 ? 'no-photo' : ''}`}>
        {seg.photos.length > 0 && (
          <div class="segment-photo">
            <img
              src={seg.photos[0].thumb}
              alt={`Route photo near mile ${seg.photos[0].mile.toFixed(1)}`}
              loading="lazy"
              decoding="async"
              class="rounded"
            />
          </div>
        )}
        <div class="segment-content">
          <h3 class="text-xl font-display text-amber-400">{seg.name}</h3>
          <div class="flex items-center gap-3 text-sm text-cream-200 mt-1 mb-2">
            <span>{seg.distFromStart} from start</span>
            <span>·</span>
            <span>{seg.length}</span>
            <span>·</span>
            <div
              class="star-rating"
              style={`--rating: ${seg.difficulty};`}
              aria-label={`Difficulty: ${seg.difficulty} out of 5 stars`}
              role="img"
            ></div>
          </div>
          <p class="text-cream-100 leading-relaxed">{seg.description}</p>
        </div>
      </article>
    ))}
  </div>
</section>
```

**Scoped `<style>` block — ALL layout CSS here, not in global.css:**

1. **Topo background** on `.route-explainer-section`:
   - `background-color: var(--color-forest-950)` (slightly darker than body for visual distinction)
   - `background-image` using SVG data URI with contour lines (extend the existing `.topo-divider` pattern from global.css but with 3 contour paths and `background-repeat: repeat` on both axes, `background-size: 400px 120px`)
   - SVG stroke color: hardcode `%233d6b3d` (the hex for forest-700) — do NOT use CSS custom properties inside the data URI
   - Add subtle top/bottom border: `border-top: 1px solid var(--color-forest-700); border-bottom: 1px solid var(--color-forest-700);`

2. **Segment card grid** (`.segment-card`):
   - Mobile (default): `display: grid; grid-template-columns: 1fr; grid-template-areas: "photo" "content"; gap: 1.5rem;`
   - When `.no-photo`: `grid-template-areas: "content"; grid-template-columns: 1fr;`
   - Add `margin-bottom: 2rem; padding-bottom: 2rem; border-bottom: 1px solid var(--color-forest-700);` to separate segments
   - Last segment: no bottom border (`&:last-child { border-bottom: none; }` — use `.segment-card:last-child` selector in Astro scoped styles)
   - Tablet+ (`@media (min-width: 768px)`):
     - `grid-template-columns: min(280px, 35%) 1fr; grid-template-areas: "photo content"; align-items: start;`
     - Alternate photo side: `.segment-card:nth-child(even) { grid-template-columns: 1fr min(280px, 35%); grid-template-areas: "content photo"; }`
     - `.no-photo` at tablet+: single column `grid-template-columns: 1fr;`

3. **Grid area assignments:**
   - `.segment-photo { grid-area: photo; }`
   - `.segment-content { grid-area: content; }`

4. **Star rating** (`.star-rating`):
   ```css
   .star-rating {
     --percent: calc(var(--rating) / 5 * 100%);
     display: inline-block;
     font-size: 1rem;
     line-height: 1;
     color: var(--color-amber-500); /* fallback */
     background: linear-gradient(
       to right,
       var(--color-amber-500) var(--percent),
       var(--color-forest-700) var(--percent)
     );
     -webkit-background-clip: text;
     background-clip: text;
     -webkit-text-fill-color: transparent;
   }
   .star-rating::before {
     content: "★★★★★";
   }
   ```

5. **Photo styling:**
   - `.segment-photo img { width: 100%; height: auto; object-fit: cover; }`

- Do NOT forget `-webkit-background-clip: text` alongside `background-clip: text`
- Do NOT forget the `color: var(--color-amber-500)` fallback before the clip rules
- Guard against empty photos array (the `seg.photos.length > 0` check handles this)
