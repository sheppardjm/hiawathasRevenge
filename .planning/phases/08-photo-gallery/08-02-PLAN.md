<task type="auto">
  <name>Task 1: Create copy-images.js pipeline step</name>
  <files>scripts/copy-images.js</files>
  <action>
    Create `scripts/copy-images.js` as an ESM module using top-level await.

    Follow the same structure and conventions as `generate-thumbnails.js`:

    1. Add JSDoc comment block:
       ```
       /**
        * copy-images.js
        *
        * Copies source JPEG images from images/ to public/images/ so they
        * can be served as full-resolution lightbox assets by Astro's static server.
        *
        * Usage: node scripts/copy-images.js
        */
       ```

    2. Import fs (readdirSync, mkdirSync, copyFileSync, existsSync), path (join, extname, dirname), url (fileURLToPath).

    3. Derive `__dirname` using `dirname(fileURLToPath(import.meta.url))`.

    4. Set constants:
       - `ROOT = join(__dirname, '..')`
       - `SRC_DIR = join(ROOT, 'images')`
       - `OUT_DIR = join(ROOT, 'public', 'images')`

    5. `mkdirSync(OUT_DIR, { recursive: true })` — create output dir if absent.

    6. Filter source files: `readdirSync(SRC_DIR).filter(f => extname(f).toLowerCase() === '.jpg')` — same pattern as generate-thumbnails.js, naturally excludes `inspiration/` subdirectory.

    7. Copy each file:
       ```javascript
       let copied = 0;
       for (const file of files) {
         const src = join(SRC_DIR, file);
         const dest = join(OUT_DIR, file);
         copyFileSync(src, dest);
         copied++;
       }
       ```

    8. Log summary: `console.log(`Copied ${copied} images to public/images/`);`

    Important: Use `copyFileSync` (not symlinks) — symlinks break in production builds and CI. The source JPGs total ~40-60MB which is acceptable for a static site.

    Do NOT rename or normalize filenames — the lightbox `href` uses the original `photo.filename` from photos.json, which maps to the source filename as-is.
  </action>
  <verify>
    Run: `PATH="/usr/local/opt/node/bin:$PATH" node scripts/copy-images.js`
    Expect:
    - Script completes without error
    - Logs "Copied 55 images to public/images/" (or similar count matching source JPGs)
    - `ls public/images/*.jpg | wc -l` matches `ls images/*.jpg | wc -l`
    - Spot-check: `ls -la public/images/ | head -5` shows JPG files with correct sizes
  </verify>
