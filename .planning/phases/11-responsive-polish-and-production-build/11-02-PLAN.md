    Add:

    ```css
    /* prefers-reduced-motion — suppress Leaflet CSS transitions (DSGN-06) */
    @media (prefers-reduced-motion: reduce) {
      .leaflet-zoom-anim .leaflet-zoom-animated {
        transition: none;
      }
      .leaflet-fade-anim .leaflet-popup {
        transition: none;
      }
      .leaflet-fade-anim .leaflet-tile {
        transition: none;
      }
      .leaflet-pan-anim .leaflet-tile {
        transition: none;
      }
    }
    ```

    This block suppresses:
    - Zoom animation on the map tiles (`.leaflet-zoom-anim .leaflet-zoom-animated`)
    - Popup fade-in/out (`.leaflet-fade-anim .leaflet-popup`)
    - Tile fade-in during loading (`.leaflet-fade-anim .leaflet-tile`)
    - Pan animation on tiles (`.leaflet-pan-anim .leaflet-tile`)

    These are all inside `@layer base` which overrides `@layer leaflet` via the cascade layer order. No `!important` needed.

    **Note:** Chart.js already has `animation: false` (ElevationProfile.astro line 87). PhotoSwipe 5 automatically disables animations for reduced motion. Neither needs CSS overrides.
