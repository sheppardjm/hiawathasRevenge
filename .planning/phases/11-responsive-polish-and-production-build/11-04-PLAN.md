    Key changes:
    - Remove `import node from '@astrojs/node';` line
    - Remove `adapter: node({ mode: 'standalone' }),` line

    **src/pages/admin.astro:**

    Remove the `export const prerender = false;` line (currently line 5). The `if (import.meta.env.PROD) { return Astro.redirect('/'); }` guard already exists and will continue to work — in static mode, Astro's `Astro.redirect()` emits a `<meta http-equiv="refresh" content="0;url=/">` tag. The admin page will still be prerendered into `dist/admin/index.html`, but it immediately redirects to `/`. This is acceptable — no sensitive data is exposed.

    Remove ONLY the `export const prerender = false;` line. Do NOT change anything else in admin.astro.

    **src/pages/api/save-manifest.ts:**

    Remove the `export const prerender = false;` line (currently line 5). Without this flag and without an adapter, Astro will skip this endpoint in the static build entirely — it won't appear in dist/. The endpoint will still work in `npm run dev` because the Astro dev server handles API routes regardless of adapter configuration.

    Remove ONLY the `export const prerender = false;` line. Do NOT change anything else in save-manifest.ts.
  </action>
