  **Step 3 — Add the ::before CSS block to the `<style>` section.**

  Insert the following CSS into the existing `<style>` block in index.astro, BEFORE the `scroll-margin-top` rule block (which is the last rule in the style block). Add it after the `.gpx-download` reduced-motion rule and before the NAV-03 anchor offset comment.

  ```css
  /* Phase 49: Route Map + Gallery section background imagery
     Extends Phase 47 History section ::before pattern.
     Sections are w-full — ::before with inset: 0 fills full viewport width.
     IntersectionObserver in HiawathaExplainer.astro toggles bg-visible
     on ALL [data-bg-fade] elements globally — zero JS changes needed. */

  :global(#route),
  :global(#gallery) {
    position: relative;
  }

  :global(#route)::before,
  :global(#gallery)::before {
    content: '';
    position: absolute;
    inset: 0;
    background-size: cover;
    background-position: center;
    opacity: 0;
    transition: opacity 0.6s ease;
    pointer-events: none;
    z-index: 0;
    filter: sepia(80%) saturate(20%) brightness(0.6);
  }

  :global(#route) > *,
  :global(#gallery) > * {
    position: relative;
    z-index: 1;
  }

  :global(#route.bg-visible)::before,
  :global(#gallery.bg-visible)::before {
    opacity: 0.08;
  }

  :global(#route)::before {
    background-image: url('/thumbs/inspiration/route-bg.webp');
  }

  :global(#gallery)::before {
    background-image: url('/thumbs/inspiration/gallery-bg.webp');
  }

  @media (prefers-reduced-motion: reduce) {
    :global(#route)::before,
    :global(#gallery)::before {
      transition: none;
      opacity: 0.04;
    }
  }

  @media (prefers-color-scheme: light) {
    :global(#route)::before,
    :global(#gallery)::before {
      filter: sepia(80%) saturate(15%) brightness(1.2);
    }

    :global(#route.bg-visible)::before,
    :global(#gallery.bg-visible)::before {
      opacity: 0.12;
    }
  }
  ```

  **CRITICAL: Use `:global()` on every selector.** Without it, Astro's scoped styles silently fail — the CSS compiles but never matches the DOM elements.

  **CRITICAL: z-index layering.** `::before` gets `z-index: 0`, section children (`> *`) get `position: relative; z-index: 1`. This ensures map tiles, gallery photos, and all interactive elements remain above the background layer.
