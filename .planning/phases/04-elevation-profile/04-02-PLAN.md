<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
Chart.js elevation profile showing elevation (feet) vs. distance (miles) for the 101.98-mile Hiawatha's Revenge route. The chart uses an amber line with subtle fill, responsive height (140px mobile, 180px tablet/desktop), and lazy-loads via IntersectionObserver.
  </what-built>
  <how-to-verify>
Open http://localhost:4321 in Chrome (dev server should be running).

**1. Chart renders with correct data:**
- Scroll down past the route map to the "Elevation Profile" section
- The chart should appear with an amber/gold line on a dark background
- Y-axis should show elevation in feet (expect range roughly 600–1000 ft)
- X-axis should show distance in miles (expect range 0–102 miles)
- The profile line should show elevation variation across the route
- If Y-axis shows values ~194–294, the meters-to-feet conversion is broken

**2. Axis labels and formatting:**
- Y-axis should have a label "Elevation (ft)" and tick labels like "700 ft", "800 ft"
- X-axis should have a label "Distance (miles)" with numeric mile markers
- Hover over the chart — tooltip should show "Mile X.X" and "NNN ft"

**3. Responsive height check:**
- On desktop: chart container should be approximately 180px tall
- Open Chrome DevTools > Toggle Device Toolbar (Ctrl+Shift+M)
- Select a mobile viewport (e.g., iPhone SE, 375px wide)
- Chart should shrink to approximately 140px tall
- Switch to tablet (e.g., iPad, 768px wide) — chart should be 180px tall
- No overflow or clipping in any viewport

**4. Lazy-loading (Network tab — most important check):**
- Open Chrome DevTools > Network tab
- Hard refresh the page (Ctrl+Shift+R)
- BEFORE scrolling: look at the loaded JS chunks — there should be NO chart.js-related chunks
- Scroll down toward the elevation chart section
- Chart.js chunk(s) and route-data.json should appear in the Network tab ONLY when the chart section enters the viewport
- This confirms ELEV-04 and success criterion 4

**5. Visual quality:**
- The amber line should be clearly visible against the dark background
- The semi-transparent fill below the line should add depth without overwhelming
- Grid lines should be subtle (barely visible)
- The chart should feel integrated with the Forest Service visual identity

**If everything looks good:** Type "approved"
**If adjustments needed:** Describe what needs to change (e.g., "Y-axis shows meters not feet", "chart too tall on mobile", "chart doesn't load lazily")
