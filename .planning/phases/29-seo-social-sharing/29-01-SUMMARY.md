## Decisions Made

- **Domain placeholder:** Used `https://hiawathasrevenge.com` with a TODO comment since the actual deployment URL is TBD. Owner must update before going live.
- **JPEG quality 75:** Produces 228KB file — above the 50-150KB guideline but appropriate for a full-resolution landscape hero photo. Social crawlers have no meaningful size limit on OG images.
- **Sharp crop strategy:** Resize source (2048x1536) to 1200px wide (→ 1200x900), then extract `top = (900-630)/2 = 135` pixels down for a centered 1200x630 strip. Keeps the middle of the image (sky + forest midpoint) rather than top-cropping.
- **set:html for JSON-LD:** Astro requires `set:html` directive to inject raw content into `<script>` tags. Using a text child would be sanitized/escaped.
