  <action>
    **Step A: Install to-ico**
    Run `npm install --save-dev to-ico` to add the ICO encoding package.

    **Step B: Replace public/favicon.svg**
    Replace the tree-emoji SVG with the shield badge SVG. Use a square viewBox (56x56) with the BaseLayout.astro shield-motif path recentered horizontally (+14 to all x-coordinates):

    Original path (28x56 viewBox): `M14 0 L0 38 Q2 36 8 34 L12 48 L14 56 L16 48 L20 34 Q26 36 28 38 Z`
    Recentered path (56x56 viewBox): `M28 0 L14 38 Q16 36 22 34 L26 48 L28 56 L30 48 L34 34 Q40 36 42 38 Z`

    The SVG must:
    - Use `xmlns="http://www.w3.org/2000/svg"` (standalone file, not in-document)
    - Have a forest-green background rect (`#1a2e1a`) with `rx="3"` for slight rounding
    - Use amber fill (`#c8973e`) for the shield path
    - Include CSS classes (`.bg` and `.shield`) -- no dark-mode media query needed since the forest-green background already works on both light and dark tab bars
    - NOT reference `<use href="#shield-motif">` (standalone SVG cannot access document DOM symbols)
    - NOT use badge.svg (too complex for favicon sizes)

    Exact content:
    ```svg
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 56 56">
      <style>
        .bg { fill: #1a2e1a; }
        .shield { fill: #c8973e; }
      </style>
      <rect width="56" height="56" class="bg" rx="3"/>
      <path d="M28 0 L14 38 Q16 36 22 34 L26 48 L28 56 L30 48 L34 34 Q40 36 42 38 Z" class="shield"/>
    </svg>
    ```

    **Step C: Create scripts/generate-favicons.js**
    Follow the pattern from `scripts/generate-og-image.js` (ESM, sharp import, __dirname setup, console.log confirmation).

    The script must:
    1. Define FAVICON_SVG as a Buffer containing the shield SVG with square 56x56 viewBox, solid `#1a2e1a` background rect, and `#c8973e` amber shield path (same coordinates as public/favicon.svg but without CSS classes -- use inline fill attributes since sharp's SVG renderer does not process `<style>` blocks reliably)
    2. Generate `public/apple-touch-icon.png`: sharp(FAVICON_SVG).resize(180, 180).flatten({ background: '#1a2e1a' }).png().toFile(...)
    3. Generate `public/favicon.ico`: sharp(FAVICON_SVG).resize(32, 32).flatten({ background: '#1a2e1a' }).png().toBuffer() then pass to toIco([buffer]) and writeFileSync the result
    4. Log success messages for each file generated

    Use `import sharp from 'sharp'`, `import toIco from 'to-ico'`, `import { writeFileSync } from 'fs'`, `import { fileURLToPath } from 'url'`, `import { dirname, join } from 'path'`.

    **Step D: Test the generation script standalone**
    Run `node scripts/generate-favicons.js` and verify it completes without error. Confirm both `public/apple-touch-icon.png` and `public/favicon.ico` exist and have non-zero size.
