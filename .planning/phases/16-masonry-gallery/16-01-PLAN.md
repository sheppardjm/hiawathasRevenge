<task type="auto">
  <name>Task 2: Rewrite PhotoGallery.astro from grid to CSS columns masonry with featured treatment</name>
  <files>src/components/PhotoGallery.astro</files>
  <action>
Rewrite `src/components/PhotoGallery.astro` to use a CSS columns masonry layout with natural aspect ratios and featured photo treatment. The `<script>` block (PhotoSwipe init + map:photoClick bridge) stays almost identical — only the HTML template and styles change.

**Frontmatter changes:**

Update the `PhotoEntry` type to include the optional `featured` field:

```typescript
type PhotoEntry = {
  id: string;
  filename: string;
  thumb: string;
  mile: number;
  lat?: number;
  lon?: number;
  featured?: boolean;
};
```

Keep the existing `parseDims` function and `photosData` import exactly as-is.

**Template changes:**

Replace the gallery container from:
```html
<div id="photo-gallery" class="grid grid-cols-2 sm:grid-cols-3 lg:grid-cols-4 gap-2">
```

to:
```html
<div id="photo-gallery" class="columns-1 sm:columns-2 lg:columns-3 gap-3">
```

Replace each `<a>` element. Old:
```html
<a
  href={`/images/${photo.filename}`}
  data-pswp-width={dims.w}
  data-pswp-height={dims.h}
  data-cropped="true"
  target="_blank"
  rel="noopener"
  class="block overflow-hidden"
>
  <img
    src={photo.thumb}
    alt=""
    loading="lazy"
    decoding="async"
    class="w-full aspect-square object-cover"
  />
</a>
```

New:
```jsx
<a
  href={`/images/${photo.filename}`}
  data-pswp-width={dims.w}
  data-pswp-height={dims.h}
  target="_blank"
  rel="noopener"
  class:list={[
    "block mb-3 break-inside-avoid overflow-hidden rounded-sm",
    photo.featured && "featured-photo"
  ]}
>
  <img
    src={photo.thumb}
    alt=""
    loading="lazy"
    decoding="async"
    class="w-full h-auto block"
  />
</a>
```

Key changes vs old:
- **Removed** `data-cropped="true"` — thumbnails are no longer cropped, so this PhotoSwipe hint is inaccurate
- **Added** `mb-3` for vertical gutter between items (CSS columns `gap-*` only sets column-gap, not row gap)
- **Added** `break-inside-avoid` to prevent photos splitting across column boundaries
- **Added** `rounded-sm` for subtle border radius
- **Added** `class:list` with conditional `featured-photo` class for featured photos
- **Replaced** `aspect-square object-cover` on `<img>` with `h-auto` for natural aspect ratios
- **Added** `block` to `<img>` to eliminate inline baseline gap

**Style block:**

Add a `<style>` block (between the template and `<script>`) for the featured photo treatment:

```css
<style>
  .featured-photo {
    column-span: all;
    margin-bottom: 0.75rem;
  }

  .featured-photo img {
    max-height: 60vh;
    object-fit: cover;
    width: 100%;
  }
</style>
```

This makes featured photos span all columns as a full-width editorial moment. The `max-height: 60vh` with `object-fit: cover` prevents landscape photos from dominating the viewport vertically. The `column-span: all` intentionally breaks the masonry flow — this is by design, creating a visual pause.

**Script block:**

Keep the entire `<script>` block exactly as-is. The PhotoSwipe init (`gallery: '#photo-gallery'`, `children: 'a'`) and the `map:photoClick` bridge are unchanged. CSS columns do NOT reorder DOM elements, so `photoIndex` remains correct.

3. `<style>` block (featured-photo rules)
4. `<script>` block (PhotoSwipe init + map bridge — unchanged)
