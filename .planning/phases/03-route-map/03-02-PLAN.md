<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
Interactive Leaflet route map with CyclOSM terrain tiles, 100-mile GPX route polyline in amber (#c8973e), gesture handling for mobile, reset view button, and lazy-loading via scroll + IntersectionObserver.
  </what-built>
  <how-to-verify>
Open http://localhost:4321 in Chrome (dev server should be running).

**1. Map renders with route visible:**
- Scroll down to the "Explore the Route" section
- The map should appear with CyclOSM terrain tiles (light background with bicycle/outdoor styling, green terrain colors)
- The 100-mile route polyline should be visible in amber/gold color
- The route should cover the Hiawatha National Forest area (Upper Peninsula Michigan, near Munising)
- Zoom in/out — route should remain visible at all zoom levels

**2. Tile aesthetic check:**
- CyclOSM tiles should have an outdoor/terrain feel with greens and earthy tones
- The amber polyline should contrast well against the tile background
- If the polyline is hard to see, note the issue — color or weight may need adjustment

**3. Attribution visible:**
- Look at the bottom-right corner of the map
- "CyclOSM | Map data: OpenStreetMap contributors" attribution text should be visible

**4. Gesture handling:**
- On desktop: Try scrolling with mouse wheel while cursor is over the map — it should show a "Use Ctrl + scroll to zoom" message instead of zooming
- Ctrl+scroll should zoom the map
- Click-drag should pan the map

**5. Reset button:**
- Pan or zoom the map away from the default view
- Click the reset button (circular arrow icon, top-left, below zoom buttons)
- Map should snap back to the initial fitBounds view showing the full route

**6. Lazy-loading (Network tab):**
- Open Chrome DevTools > Network tab
- Hard refresh the page (Ctrl+Shift+R)
- Before scrolling, check that no leaflet chunk appears in the network requests
- Scroll down toward the map — Leaflet JS and route-data.json should load as you scroll

**If everything looks good:** Type "approved"
**If adjustments needed:** Describe what needs to change (e.g., "polyline too thin", "color hard to see on tiles", "tiles look bad")
