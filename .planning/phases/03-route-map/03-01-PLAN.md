**Step 1: Create `src/components/` directory and `RouteMap.astro`.**

Create `src/components/RouteMap.astro` following the mkUltra RouteMap.astro structure but scoped to Phase 3 features only. This is a plain .astro component (NO client: directive — lazy-init is handled manually in the script block).

**Component structure:**

**Frontmatter (---):** Empty or comment-only. No server-side imports needed.

**Template:** A single `<div id="map" class="route-map"></div>`. No other HTML.

**Style block (`<style>`):**
```css
.route-map {
  width: 100%;
  height: 60vh;
  min-height: 400px;
  position: relative;
  z-index: 0;
}
```
The explicit height is REQUIRED — Leaflet renders into a 0px-tall invisible div without it (Pitfall 3 from research). `z-index: 0` creates a new stacking context so Leaflet's internal z-indices don't leak.

**Script block (`<script>`):** Contains all map logic. Structure it as follows:

**`initMap()` async function** containing (in this exact order):

1. **Dynamic import Leaflet:**
   ```javascript
   const L = (await import('leaflet')).default;
   ```
   MUST be dynamic import (not static top-level). Static import causes SSR "window is undefined" error.

2. **Wire GestureHandling BEFORE L.map():**
   ```javascript
   const { GestureHandling } = await import('leaflet-gesture-handling');
   L.Map.addInitHook('addHandler', 'gestureHandling', GestureHandling);
   ```
   `addInitHook` registers a handler that runs during map construction. Calling it AFTER `L.map()` = gesture handling silently does nothing (Pitfall 2 from research).

3. **Create map with gestureHandling enabled:**
   ```javascript
   const map = L.map('map', { gestureHandling: true });
   ```

4. **CyclOSM tile layer:**
   ```javascript
   L.tileLayer('https://{s}.tile-cyclosm.openstreetmap.fr/cyclosm/{z}/{x}/{y}.png', {
     attribution: '<a href="https://github.com/cyclosm/cyclosm-cartocss-style/releases" title="CyclOSM - Open Bicycle render">CyclOSM</a> | Map data: &copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a> contributors',
     subdomains: 'abc',
     maxZoom: 20
   }).addTo(map);
   ```
   No API key required. Attribution is legally required (OSM license) and handled by Leaflet's attribution control automatically.

5. **Custom Reset Control** (L.Control.extend):
   ```javascript
   const ResetControl = L.Control.extend({
     options: { position: 'topleft' },
     onAdd() {
       const container = L.DomUtil.create('div', 'leaflet-bar leaflet-control');
       const btn = L.DomUtil.create('a', '', container);
       btn.href = '#';
       btn.title = 'Reset view';
       btn.setAttribute('role', 'button');
       btn.setAttribute('aria-label', 'Reset map to default view');
       btn.innerHTML = '&#8635;';
       L.DomEvent.disableClickPropagation(container);
       L.DomEvent.on(btn, 'click', (e) => {
         L.DomEvent.preventDefault(e);
         map.fitBounds(initialBounds, { padding: [20, 20] });
         map.closePopup();
       });
       return container;
     }
   });
   new ResetControl().addTo(map);
   ```
   Note: `initialBounds` is defined below after the polyline is created. The reset button click handler captures `initialBounds` via closure — this works because the button is never clicked before the polyline exists (user has to scroll to see the map first).

6. **Fetch route data and render polyline:**
   ```javascript
   const routeData = await fetch('/data/route-data.json').then(r => r.json());
   const latlngs = routeData.points.map((pt) => [pt.lat, pt.lon]);

   const routeLine = L.polyline(latlngs, {
     color: '#c8973e',
     weight: 3,
     opacity: 0.85,
     smoothFactor: 1
   }).addTo(map);

   map.fitBounds(routeLine.getBounds(), { padding: [20, 20] });
   const initialBounds = routeLine.getBounds();
   ```
   - Color `#c8973e` (amber-500) is the project's primary accent and contrasts well on CyclOSM's light terrain tiles (Pitfall 5 from research). Do NOT use mkUltra's `#d4d4d4` which was for dark tiles.
   - `smoothFactor: 1` is default — keeps polyline accurate to GPS points.
   - `padding: [20, 20]` gives breathing room around the route bounds.

**Lazy-init pattern** (outside `initMap()`, at module scope):

```javascript
let mapInitialized = false;
const mapEl = document.getElementById('map');

function tryInitMap() {
  if (!mapInitialized) {
    mapInitialized = true;
    initMap();
  }
}

if (mapEl) {
  window.addEventListener('scroll', tryInitMap, { once: true, passive: true });
  const observer = new IntersectionObserver(
    (entries) => {
      if (entries[0].isIntersecting) {
        observer.disconnect();
        tryInitMap();
      }
    },
    { rootMargin: '0px' }
  );
  observer.observe(mapEl);
}
```
- Scroll event is the PRIMARY trigger (fires on first scroll, loads map eagerly).
- IntersectionObserver is the FALLBACK (handles direct anchor navigation to #route).
- `rootMargin: '0px'` (not '200px') — matches mkUltra production pattern, avoids eager preload in Lighthouse.
- `{ once: true, passive: true }` on scroll listener auto-removes after first fire and allows smooth scrolling.
