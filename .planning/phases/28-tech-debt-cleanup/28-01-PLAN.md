<task type="auto">
  <name>Task 3: DEBT-03 — Add Firefox-compatible star rating gradient fallback</name>
  <files>src/components/RouteExplainer.astro</files>
  <action>
    Restructure the `.star-rating` CSS in RouteExplainer.astro's `<style>` block to use an `@supports` guard for progressive enhancement.

    Replace the current `.star-rating` CSS block with:

    ```css
    .star-rating {
      --percent: calc(var(--rating) / 5 * 100%);
      display: inline-block;
      font-size: 1rem;
      line-height: 1;
      /* Solid amber fallback for browsers without background-clip: text support */
      color: var(--color-amber-500);
    }

    @supports (background-clip: text) or (-webkit-background-clip: text) {
      .star-rating {
        background: linear-gradient(
          to right,
          var(--color-amber-500) var(--percent),
          var(--color-forest-700) var(--percent)
        );
        -webkit-background-clip: text;
        background-clip: text;
        -webkit-text-fill-color: transparent;
        color: transparent;
      }
    }
    ```

    Key changes from the current code:
    - Base `.star-rating` now ONLY sets the solid amber fallback color (no gradient properties)
    - Gradient, background-clip, -webkit-text-fill-color, and the new `color: transparent` are all inside the `@supports` guard
    - `color: transparent` is the standard CSS companion to `-webkit-text-fill-color: transparent` — this is what Firefox needs to properly reveal the background gradient through the text
    - Preserve any existing `display`, `font-size`, `line-height` properties from the current rule (check current code and keep them)

    IMPORTANT: Do NOT touch the `.star-rating::before` pseudo-element — it provides the star characters and should remain unchanged. Do NOT touch RouteMap.astro's `.panel-stars` — it uses a different, non-gradient technique.
