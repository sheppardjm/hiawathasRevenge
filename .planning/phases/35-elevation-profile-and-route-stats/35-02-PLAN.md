  <files>src/components/RouteStats.astro</files>
  <action>
    **1. Import routes.json in Astro frontmatter:**
    Add to the existing frontmatter block (between the `---` fences), after the existing `getEntry` import:
    ```javascript
    import routesManifest from '../../public/data/routes.json';
    ```

    **2. Add comparison grid HTML:**
    After the closing `</div>` of `.stats-grid`, add a comparison section with a heading and a 3-column grid. Each card shows one route's name, miles, elevation, and sector count. The 100mi card gets the `is-active` class by default (matching `routesManifest.defaultRoute`).

    ```html
    <h3 class="comparison-heading">Compare Routes</h3>
    <div class="route-comparison">
      {routesManifest.routes.map(route => (
        <div
          class:list={['comparison-card', { 'is-active': route.id === routesManifest.defaultRoute }]}
          data-route-id={route.id}
          style={`--route-color: ${route.color}`}
        >
          <div class="comparison-name">{route.name}</div>
          <div class="comparison-stat">
            <span class="stat-value">{Math.round(route.totalMiles)}</span>
            <span class="stat-label">Miles</span>
          </div>
          <div class="comparison-stat">
            <span class="stat-value">{route.elevationGainFeet.toLocaleString()}</span>
            <span class="stat-label">Ft Climbing</span>
          </div>
          <div class="comparison-stat">
            <span class="stat-value">{route.sectorIds.length}</span>
            <span class="stat-label">Sectors</span>
          </div>
        </div>
      ))}
    </div>
    ```

    The `style={`--route-color: ${route.color}`}` sets a CSS custom property per card, used by the `.is-active` border styling. This avoids needing JS to set the active color — CSS handles it via the custom property.

    **3. Add active highlight to the existing `<script>` block:**
    In the `<script>` block added by Plan 35-01 (which already has the `route:change` listener for stat updates), add comparison card highlighting inside the same listener callback. After the stat update lines, add:

    ```javascript

    document.querySelectorAll('.comparison-card').forEach(card => {
      card.classList.toggle('is-active', card.dataset.routeId === e.detail.routeId);
    });
    ```

    This goes inside the existing `window.addEventListener('route:change', async (e) => { ... })` handler, after the stat update code. Do NOT create a second event listener — consolidate into the existing one.
