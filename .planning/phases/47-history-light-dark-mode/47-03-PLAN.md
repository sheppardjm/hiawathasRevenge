    **Part C: Update HiawathaExplainer.astro CSS**

    In `src/components/HiawathaExplainer.astro`, make these CSS changes:

    1. **Add CSS breakout to `.subsection-bg::before`** to escape the `max-w-5xl` container:
       ```css
       .subsection-bg::before {
         content: '';
         position: absolute;
         /* Replace inset: 0 with explicit breakout */
         top: 0;
         bottom: 0;
         left: 50%;
         width: 100vw;
         transform: translateX(-50%);
         background-size: cover;
         background-position: center;
         opacity: 0;
         transition: opacity 0.6s ease;
         pointer-events: none;
         z-index: 0;
         filter: sepia(80%) saturate(20%) brightness(0.6);
       }
       ```
       The key change: replace `inset: 0` with `top: 0; bottom: 0; left: 50%; width: 100vw; transform: translateX(-50%)`. This makes the ::before break out of its positioned ancestor to span the full viewport width.

    2. **Add `overflow: hidden` to `.hiawatha-section`** to prevent the breakout from causing horizontal scroll:
       ```css
       .hiawatha-section {
         background-color: var(--color-forest-950);
         position: relative;
         overflow: hidden;
       }
       ```

    3. **Update the three `background-image` URLs** to point to new inspiration images:
       ```css
       .poem-section::before {
         background-image: url('/thumbs/inspiration/poem-bg.webp');
       }

       .forest-section::before {
         background-image: url('/thumbs/inspiration/forest-bg.webp');
       }

       .ride-section::before {
         background-image: url('/thumbs/inspiration/ride-bg.webp');
       }
       ```

    4. **Do NOT change** the `.bg-visible::before` opacity values, transition, filter, or reduced-motion rules. The scroll-triggered IntersectionObserver logic in the `<script>` block is unchanged.

    5. **Do NOT change** any HTML structure. The breakout is CSS-only.

    **Why `overflow: hidden` on `.hiawatha-section`:** The ::before now extends to 100vw which may exceed the section width. The parent section needs `overflow: hidden` to clip the horizontal overflow and prevent a scrollbar. This is the standard CSS "full-bleed inside constrained container" pattern.

    **Why NOT restructure HTML:** Moving the background `<div>` outside `max-w-5xl` would require restructuring the editorial grid. The CSS breakout achieves the same visual result with zero HTML changes and zero risk to the existing layout.
