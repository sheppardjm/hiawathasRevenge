**Create `src/components/HeroSection.astro`** with the following structure:

The component receives no props. The hero photo filename is hardcoded based on the Task 1 decision.

**HTML structure:**
```html
<section class="hero">
  <img class="hero-img" ... />
  <div class="hero-overlay" aria-hidden="true"></div>
  <div class="hero-content">
    <h1 class="hero-title">Hiawatha's Revenge</h1>
    <p class="hero-tagline">100 miles through Michigan's Hiawatha National Forest</p>
    <div class="hero-date-block">
      <span class="hero-date-label">Ride Date</span>
      <time class="hero-date" datetime="2026-06-06">June 6, 2026</time>
    </div>
  </div>
</section>
```

**`<img>` attributes (LCP-critical — all required):**
- `src="/images/[SELECTED_HERO_FILENAME]"` — the photo chosen in Task 1
- `srcset="/images/[SELECTED_HERO_FILENAME] 2048w"` — single source at native resolution
- `sizes="100vw"` — image spans full viewport width
- `alt=""` — empty string (decorative image, WCAG-correct; text content is in overlay)
- `width="2048"` and `height="1536"` — prevents CLS
- `fetchpriority="high"` — marks as LCP element for browser prioritization
- `loading="eager"` — no lazy loading for above-fold hero
- `decoding="async"` — non-blocking decode

**CSS (scoped `<style>` block in the component):**

`.hero`:
- `position: relative`
- `width: 100%`
- `height: 100svh` with `min-height: 480px` floor
- `overflow: hidden`
- `display: flex; align-items: flex-end` — content anchored at bottom for dramatic effect

`.hero-img`:
- `position: absolute; inset: 0`
- `width: 100%; height: 100%`
- `object-fit: cover; object-position: center`

`.hero-overlay`:
- `position: absolute; inset: 0`
- `background: linear-gradient(to top, rgba(13, 26, 13, 0.85) 0%, rgba(13, 26, 13, 0.4) 50%, rgba(13, 26, 13, 0.1) 100%)`
  (forest-950 = `#0d1a0d` = rgb(13,26,13); darkest at bottom where text lives)

`.hero-content`:
- `position: relative; z-index: 1`
- `width: 100%; padding: 2rem`
- `max-width: 64rem; margin: 0 auto` — constrain text width on ultra-wide screens

`.hero-title`:
- `font-family: var(--font-display)`
- `font-size: clamp(2rem, 5vw + 0.5rem, 4.5rem)` — fluid from ~32px at 375px to ~72px at 1280px
- `font-weight: 800`
- `color: var(--color-amber-500)`
- `text-shadow: var(--shadow-text)`
- `text-transform: uppercase`
- `letter-spacing: 0.04em`
- `line-height: 1.1`
- `margin: 0`

`.hero-tagline`:
- `font-family: var(--font-mono)`
- `font-size: clamp(0.875rem, 2vw, 1.25rem)` — fluid from 14px to 20px
- `color: var(--color-cream-100)`
- `margin-top: 0.5rem`
- `max-width: 36rem` — prevent overly wide lines

`.hero-date-block`:
- `margin-top: 1.5rem`
- `display: flex; flex-direction: column; gap: 0.125rem`

`.hero-date-label`:
- `font-family: var(--font-display)`
- `font-size: clamp(0.625rem, 1.5vw, 0.75rem)` — small label
- `color: var(--color-cream-200)`
- `text-transform: uppercase`
- `letter-spacing: 0.2em`

`.hero-date` (`<time>` element):
- `font-family: var(--font-display)`
- `font-size: clamp(1.25rem, 3vw, 2rem)` — prominent date, fluid from 20px to 32px
- `font-weight: 700`
- `color: var(--color-gold-500)` — gold accent, PASSES WCAG AA on forest-950 overlay
- `letter-spacing: 0.08em`

**`@supports` fallback for `100svh`:**
```css

}
```
