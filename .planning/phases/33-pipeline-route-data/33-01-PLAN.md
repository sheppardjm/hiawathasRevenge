5. Add consecutive duplicate-point deduplication BEFORE building fullPoints:
   ```
   const dedupedPts = trkpts.filter((pt, i) => {
     if (i === 0) return true;
     const prev = trkpts[i - 1];
     return pt['@_lat'] !== prev['@_lat'] || pt['@_lon'] !== prev['@_lon'];
   });
   ```
   Then use `dedupedPts` instead of `trkpts` for `fullPoints`.
