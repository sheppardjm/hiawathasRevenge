## Decisions Made

- **sun-500 for yellow/gold:** Bright saturated gold that reads unmistakably as "yellow." Requires dark text — all text set to forest-950/900.
- **amber-500 for orange:** Addresses user's "orange" request specifically. amber-500 (#c8973e) is a warm amber-orange distinct from yellow. ~7:1 contrast ratio against forest-950 text — dark text applied.
- **turquoise-700 for teal:** Dark enough (~5.5:1) for cream text to remain, preserving the site's cream-on-dark visual language in the teal section.
- **:global() selectors required:** DonateCallout.astro uses Astro scoped styles (hash attributes on class names). Parent-page CSS cannot reach into scoped child styles without `:global()`. Pattern: `.gold-section :global(.donate-message) { ... }`.
