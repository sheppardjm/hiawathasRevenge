## Decisions Made

- **Polyline vs path for animated elements:** Used `<polyline points="...">` for the zigzag/chevron animated paths instead of path `d=""` — simpler coordinate syntax for rectilinear geometric shapes, directly expresses the geometric intent
- **Middle rail at 1.5px:** The center of the 3-line rail band uses 1.5px instead of 2px (like the outer lines) to create visual depth and distinguish it as the accent line
- **Upward triangle arrowheads for berry variant:** Differs from the sideways (pointing outward) arrowheads in the floral variant to give each variant a distinct character while sharing the geometric vocabulary
- **Full removal of cycle-blossom/cycle-berry:** Completely removed since no SVG elements reference them anymore — leaving dead CSS would be misleading
