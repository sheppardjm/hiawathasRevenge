**Step 1: Fetch annotations.json and build sector annotation objects.**

AFTER the existing `const data = routeData.points.map(...)` block and BEFORE the `const canvas = ...` line, add:
```javascript
// Fetch annotations and build sector band overlays
const annotations = await fetch('/data/annotations.json').then(r => r.json());
const sectors = annotations.filter(a => a.type === 'sector');
const sectorAnnotations = {};
for (const sector of sectors) {
  sectorAnnotations[sector.id] = {
    type: 'box',
    xMin: sector.startMile,
    xMax: sector.endMile,
    // yMin/yMax intentionally omitted — auto-expands to full chart height
    backgroundColor: 'rgba(200, 151, 62, 0.15)',
    borderWidth: 0,
    drawTime: 'beforeDatasetsDraw'
  };
}
```

Key details:
- `sector.id` (e.g., `'sector-520'`) is used as the object key — chartjs-plugin-annotation 3.1.0 requires object-with-named-keys format (not array).
- `xMin`/`xMax` come directly from `sector.startMile`/`sector.endMile` — these are already in miles matching the chart's x-axis scale.
- `yMin`/`yMax` are intentionally omitted — the annotation plugin auto-expands to full chart height.
- `backgroundColor: 'rgba(200, 151, 62, 0.15)'` — amber (#c8973e) at 15% opacity. Subtle enough to not overwhelm the elevation line but visible enough to identify gravel sectors. Matches the map sector polyline color at reduced opacity.
- `borderWidth: 0` — no visible border on the bands (the fill is sufficient).
- `drawTime: 'beforeDatasetsDraw'` — renders BEHIND the elevation line so the line and fill are always visible on top of the bands.
