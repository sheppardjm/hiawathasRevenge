**Step 5: Add the `onHover` callback to the chart options (top-level, inside `options`).**

Add this AFTER the `animation: false` line, before `plugins`:
```javascript
onHover(event, _activeElements, chart) {
  const pos = Chart.helpers.getRelativePosition(event, chart);
  const miles = chart.scales.x.getValueForPixel(pos.x);
  if (miles == null) return;
  // Clamp to valid range to prevent snapping to route start/end near axis labels
  const clamped = Math.max(0, Math.min(data[data.length - 1].x, miles));
  // Dispatch CustomEvent for RouteMap crosshair sync
  window.dispatchEvent(new CustomEvent('elevation:hover', { detail: { miles: clamped } }));
  // Update crosshair line position
  chart.options.plugins.annotation.annotations.crosshair.xMin = clamped;
  chart.options.plugins.annotation.annotations.crosshair.xMax = clamped;
  chart.options.plugins.annotation.annotations.crosshair.display = true;
  chart.update('none');
},
```

**Critical:** Use `Chart.helpers.getRelativePosition` (capital C, from the imported Chart object) — this accounts for chart padding, device pixel ratio, and scale margins. The `data` variable (built from routeData.points) is in scope because onHover is inside the same function that creates it.

**Critical:** Use `chart.update('none')` — the `'none'` string argument prevents animation on each mousemove, which would cause visual judder at 60fps. Without it, Chart.js plays a transition animation per update.

**Step 6: Add mouseleave listener on the canvas element.**

AFTER the `new Chart(...)` call (still inside `initChart()`), add:

```javascript
canvas.addEventListener('mouseleave', () => {
  window.dispatchEvent(new CustomEvent('elevation:leave'));
  chart.options.plugins.annotation.annotations.crosshair.display = false;
  chart.update('none');
});
```

This hides the crosshair line and tells RouteMap to remove the bike marker when the cursor leaves the chart.

**Step 1: Add module-scope variables BEFORE the `initMap()` function definition.**

These must be at the outermost scope of the script block so the window event listeners can access them before initMap() finishes:
```javascript
let bikeMarker = null;
let routePoints = null;
let leafletMap = null;
```

**Step 2: Add the `snapByMiles` helper function at module scope (before initMap).**

```javascript
function snapByMiles(points, targetMiles) {
  let best = points[0];
  let bestDiff = Math.abs(points[0].miles - targetMiles);
  for (const pt of points) {
    const diff = Math.abs(pt.miles - targetMiles);
    if (diff < bestDiff) { bestDiff = diff; best = pt; }
  }
  return best;
}
```

This is O(n) over 456 points — fast enough for 60fps mousemove. Uses the `miles` field on each point for distance-along-route matching (NOT array index).

**Step 3: Add window event listeners at module scope (before initMap, after snapByMiles).**

```javascript
window.addEventListener('elevation:hover', (e) => {
  if (!bikeMarker || !routePoints || !leafletMap) return;
  const { miles } = e.detail;
  const pt = snapByMiles(routePoints, miles);
  bikeMarker.setLatLng([pt.lat, pt.lon]);
  if (!bikeMarker._map) bikeMarker.addTo(leafletMap);
});

window.addEventListener('elevation:leave', () => {
  if (bikeMarker && bikeMarker._map) bikeMarker.remove();
});
```

**Critical:** These listeners MUST be at module scope, NOT inside `initMap()`. The `initMap()` function runs asynchronously after the user scrolls — if the user hovers the chart before scrolling, events would fire to no listener. The guard `if (!bikeMarker || !routePoints || !leafletMap) return;` safely handles the pre-init window.

**Step 4: Inside `initMap()`, after `const map = L.map('map', { gestureHandling: true });`, assign the module-scope reference:**

```javascript
leafletMap = map;
```

**Step 5: Inside `initMap()`, after the `routeData` fetch and the `latlngs` array creation, assign the module-scope reference:**

```javascript
routePoints = routeData.points;
```

**Step 6: Inside `initMap()`, after the `routeLine` polyline is created and added to map, create the bike dot marker:**

```javascript
const bikeIcon = L.divIcon({
  html: `<svg xmlns="http://www.w3.org/2000/svg" width="16" height="16" viewBox="0 0 16 16">
    <circle cx="8" cy="8" r="6" fill="#c8973e" stroke="#1a2e1a" stroke-width="2"/>
  </svg>`,
  className: '',
  iconSize: [16, 16],
  iconAnchor: [8, 8]
});

bikeMarker = L.marker([0, 0], {
  icon: bikeIcon,
  interactive: false,
  keyboard: false,
  zIndexOffset: 1000
});
```

Key details:
- `className: ''` — REQUIRED. Removes the default `leaflet-div-icon` class which adds a white background with border.
- `iconAnchor: [8, 8]` — centers the 16x16 icon on the coordinate point.
- `interactive: false` — no click/hover events on the crosshair marker itself.
- `zIndexOffset: 1000` — draws above the route polyline.
- The marker is created but NOT added to the map yet — it appears on first elevation:hover.
- Using a simple amber circle dot with forest-green stroke instead of a full bike SVG — cleaner at small size, matches project color palette.
