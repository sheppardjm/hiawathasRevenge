Color rationale:

- `moderate` (#c8973e) — existing amber. No visual change for the majority of sectors. Stays consistent with project accent color.
- `hard` (#a0522d / sienna) — deeper reddish-brown/rust. Reads as "warning" without being alarm-red. Complements the forest service theme.

**Part A: Modify `src/components/RouteMap.astro`**

Add the `SECTOR_COLORS` object inside the `<script>` block, BEFORE the `initMap()` function (at module scope, after the `snapByMiles` function):

```javascript
const SECTOR_COLORS = {
  easy:     { line: '#8a9a5b' },
  moderate: { line: '#c8973e' },
  hard:     { line: '#a0522d' },
};
```

Then modify the sector polyline loop (currently lines 133-141). Find:
```javascript
for (const sector of sectors) {
  const sectorPts = latlngs.slice(sector.startIdx, sector.endIdx + 1);
  L.polyline(sectorPts, {
    color: '#c8973e',
    weight: 5,
    opacity: 0.85
  }).addTo(map);
}
```

Replace with:
```javascript
for (const sector of sectors) {
  const sectorPts = latlngs.slice(sector.startIdx, sector.endIdx + 1);
  const colors = SECTOR_COLORS[sector.difficulty] || SECTOR_COLORS.moderate;
  L.polyline(sectorPts, {
    color: colors.line,
    weight: 5,
    opacity: 0.85
  }).addTo(map);
}
```

Key details:
- `SECTOR_COLORS[sector.difficulty]` — looks up the color by the new difficulty field from annotations.json.
- `|| SECTOR_COLORS.moderate` — fallback to amber if difficulty is somehow missing (defensive).
- `weight` and `opacity` stay the same — only the color changes per difficulty.
- The `line` property naming is used because RouteMap only needs the polyline stroke color (no fill).
