## Tech Debt

### Phase 12: Design Foundation
- **gold-600 WCAG AA comment inaccuracy** — Inline comment labels gold-600 as part of "PASSES AA" family, but it measures 4.45:1 on forest-900 (0.05 below the 4.5 AA normal text threshold). Passes AA large text. No body text currently uses gold-600. Documentation-only issue.

### Phase 14: Ojibwe Design System (dead code from replacement)
- **Dead `.topo-divider` CSS rule** — `global.css` lines 181-188 define `.topo-divider` but all HTML references were replaced by `<FloralDivider />`. Zero callers remain. Dead weight, no visual impact.

### Pre-existing (Phase 11)
- **CSS brace imbalance in index.astro** — `@media (min-width: 640px)` block wrapping `prefers-reduced-motion` rule is missing a closing brace. The motion suppression only applies at >=640px; mobile users with reduced-motion preference still see the 0.2s transition on `.gpx-download`. Low severity, cosmetic accessibility gap.

**Total: 3 items across 3 phases (0 blockers)**
