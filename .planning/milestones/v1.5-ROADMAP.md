# Milestone v1.5: Multi-Route Support

**Status:** ✅ SHIPPED 2026-04-07
**Phases:** 33-37
**Total Plans:** 10

## Overview

Add 100k and 50k route variants alongside the existing 100-mile route with a map-based route selector, per-route elevation profiles, filtered sector display, and GPX downloads for all three distances.

**Plans**: 3 plans

## Milestone Summary

**Key Decisions:**

- Subdirectory output (public/data/{routeId}/) for per-route isolation
- Coordinate-based haversine snapping replaces mile-based for cross-route accuracy
- RouteSelector as plain DOM element (not L.Control) for flexible positioning
- Ghost polylines on map directly (not activeRouteGroup) for persistence across switches
- history.replaceState for URL hash to prevent event cascades
- Panel close at step 1.5 before clearActiveRoute to fix dead code bug
- Mutate Chart.js annotations object (not replace) to avoid Proxy infinite recursion

**Issues Resolved:**

- MAP-05 panel auto-close dead code (clearActiveRoute nulled activeSector before check)
- Chart.js v4 Proxy Object.set infinite recursion on annotation replacement
- ElevationProfile lazy-init race condition (window.__activeRouteId bridge)
- "Rapid River Truck Trail" renamed to "Ridge Rd" with Strava segment 41188200

**Issues Deferred:**

- iOS Safari device testing (requires physical device)
- Elevation gains for 100k/50k unverified against Strava/Garmin reference recordings
- astro.config.ts site URL is placeholder

**Technical Debt Incurred:**

None.
