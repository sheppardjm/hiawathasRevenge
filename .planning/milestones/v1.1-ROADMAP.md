## Milestone Summary

**Decimal Phases:** None

**Key Decisions:**

- `@theme static` over `@theme` — Tailwind v4 tree-shakes unused tokens; static forces all to :root for JS getComputedStyle access
- getCSSColor() placed inside init functions — getComputedStyle must run after document ready
- Forest creek photo selected as hero background — user chose over POV, cyclists, lake options
- CSS Grid stacking for badge overlay — absolute positioning failed with Astro scoped styles
- Inline SVG over CSS data-URI for FloralDivider — CSS data-URI cannot resolve var(--color-*) custom properties
- Hand-authored SVG paths — avoids licensing ambiguity with Neebin Studios floral set
- Attribution names Ojibwe (Anishinaabe) specifically — generic "Native American" insufficient per DSN-04
- SVG data URI hardcodes hex in RouteExplainer — CSS custom properties cannot resolve inside background-image data URIs
- CSS columns layout for masonry — only masonry approach achievable in CSS without JavaScript
- Spread conditional for featured field — keeps JSON clean, no featured: false noise
- Dead .topo-divider removed entirely (not commented) — no references remain
- WCAG comments must specify ratio and text-size applicability — gold-600 was incorrectly described

**Issues Resolved:**

- gold-600 WCAG AA comment inaccuracy (corrected to "passes AA large text only")
- Dead .topo-divider CSS rule (removed from global.css)
- CSS brace imbalance in index.astro (prefers-reduced-motion moved to top level)
- 3 duplicate photo pairs in manifest (removed, pipeline regenerated)

**Issues Deferred:** None

**Technical Debt Incurred:**

- 8 orphaned color tokens in global.css (rust-600, berry-700, berry-500, gold-600, lake-700, lake-600, lake-500, moss-600) — palette scaffolding for future use, ~200 bytes CSS
- Ojibwe community consultation recommended for cultural sensitivity review of Phase 14 design elements
