# Milestone v1.3: Interactive Map & Editorial Polish

**Status:** ✅ SHIPPED 2026-04-02
**Phases:** 23-27

## Overview

Make the route map a first-class interactive experience with sector labels, clickable detail panels, and surface-colored track — while polishing the editorial layout with better whitespace, redesigned pull quotes, parallax imagery, and additional cultural design elements.

## Milestone Summary

**Decimal Phases:** None — all phases were sequential (23-27).

**Key Decisions:**
- Build-time sector-details.json (not hardcoded in RouteExplainer) — single source of truth for panel content
- Ghost polyline pattern (not leaflet-highlightable-layers) — zero new dependencies
- HTML `<dialog>` + CSS translate — no JS animation library needed
- dialog.show() (non-modal) over showModal() — map stays interactive while panel is open
- stars field additive in annotations.json — difficulty string preserved for existing components
- Coordinate matching via 5-decimal rounding Map — 456/456 match rate
- Hardcoded hex colors in sparkline SVG — CSS vars unavailable in innerHTML-injected SVG
- Cascade fix (not component relocation) for stat legibility — specific :global() overrides, no !important
- EB Garamond Font tag without preload — drop-cap use below-fold only
- MAP-08 trade-off: show() (non-modal) preserves map interactivity at cost of no backdrop close

- VIS-02: EB Garamond Font tag was missing from BaseLayout.astro — added in Phase 27
- MAP-08: Backdrop click non-functional with dialog.show() — documented as deliberate trade-off

- Route stats dark text on amber background unreadable — cascade fix in Phase 26
