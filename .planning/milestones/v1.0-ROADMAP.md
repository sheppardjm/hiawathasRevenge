# Milestone v1.0: MVP

**Status:** ✅ SHIPPED 2026-03-31
**Phases:** 0-11
**Total Plans:** 33

## Overview

This roadmap delivered a visually immersive, static showcase site for the Hiawatha's Revenge 100-mile gravel route. The work began with Astro scaffolding and design tokens, proceeded through a two-phase build pipeline that produces clean JSON and WebP artifacts, then assembled the interactive map, elevation profile, photo gallery, and content layer that together inspire visitors to ride the route and donate to MBTN.

## Milestone Summary

**Decimal Phases:**
- Phase 0: Full-Site UAT Gap Closure (inserted after Phase 11 for post-build acceptance testing)

**Key Decisions:**
- Clone mkUltra stack exactly (Astro 6, Tailwind 4, Leaflet, Chart.js, PhotoSwipe, sharp)
- CyclOSM tiles for forest-themed bicycle cartography (no API key)
- Elevation gain computed on full 1927-point set (not simplified) — 2m filter yields 2,258 ft
- National Park font for display headings (replacing Special Elite)
- Shield SVG badge with arrowhead and curved textPath as canonical branding element
- Difficulty-based gravel sector color coding (green/amber/rust)
- Water drop SVG divIcon for restock markers (visually distinct from photo clusters)
- Direct canvas mousemove for crosshair sync (Chart.js onHover unreliable with parsing:false)
- Static build with no SSR — removed @astrojs/node adapter for flat dist/ output

**Issues Resolved:**
- Photo 404s from double /thumbs/ prefix in gallery component
- Elevation chart X-axis extending to ~120 miles instead of ~102
- Crosshair hover sync not firing (Chart.js onHover callback unreliable)
- Surface labels showing "singletrack" instead of actual terrain types
- Restock markers visually identical to photo markers

**Issues Deferred:**
- None — all identified issues resolved in Phase 0

**Technical Debt Incurred:**
- photos.json build logs [ERROR] from internal Astro file-loader when manifest absent (non-fatal, cosmetic)
- Admin page emits meta-refresh redirect in production dist/ (harmless static file)
