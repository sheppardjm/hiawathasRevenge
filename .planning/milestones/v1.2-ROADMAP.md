## Milestone Summary

**Key Decisions:**

- scarlet-600 (#dc2626) = large-text/decorative ONLY (3.00:1 on forest-900)
- FloralDivider is canonical surface for orphaned/decorative tokens
- Standalone script per image category (zero risk to existing pipeline)
- pathLength=1 + stroke-dashoffset as v1.2 animation standard
- SVG symbol placed after body tag (not head) for valid use targets
- ShieldMotif decorative by default (aria-hidden, opt-in labels)
- MET Open Access / Wikimedia CC0 for Remington illustrations
- sepia(80%) saturate(30%) brightness(0.9) as canonical historical filter
- Strava #FC5200 hardcoded, not a design token (third-party brand color)
- Named CSS Grid tracks (full/breakout/prose) for editorial layout
- linearGradient IDs scoped by sectorId to prevent duplicate-ID collisions
- :global() required for Astro scoped child component style overrides

**Issues Resolved:**

- AnimatedDivider floral variants replaced with bold geometric patterns (zigzag, chevron, diamond)
- HiawathaExplainer upgraded from linear prose to magazine editorial grid layout
- Segment cards redesigned with photo-hero layout and enhanced sparklines
- Section color variety expanded with gold/amber/teal backgrounds

**Technical Debt Carried Forward:**

- Hero image 640KB JPEG — no WebP fallback, no srcset, no preload hint
- Rapid River Truck Trail missing Strava ID (6/7 segments have links)
- Difficulty data inconsistency for 3 segments (numeric vs text systems disagree)
- Segment 520 renders gradient fallback (0 photos — intentional)
