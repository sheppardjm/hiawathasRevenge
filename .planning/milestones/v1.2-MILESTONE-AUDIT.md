## Tech Debt

### Phase 22: Animation & Polish
- **Hero image optimization:** 640KB JPEG at 2048×1536 with no WebP fallback, no responsive srcset with smaller widths, no `<link rel="preload">` hint. `fetchpriority="high"` is set. LCP on simulated 4G needs Lighthouse verification.

### Phase 20: Content & Route Enrichment
- **Rapid River Truck Trail stravaId:** Only segment without a Strava link (6/7 have links). May not have a corresponding Strava segment.
- **Difficulty data inconsistency:** Two parallel difficulty systems disagree for 3 segments. `SEGMENTS[].difficulty` (numeric 1-5, drives star ratings and shield colors) and `sector-elevations.json` difficulty (easy/moderate/hard, drives sparkline stroke color) produce contradictory visual signals within the same card for NF2266, Doe Lake, and Rapid River Truck Trail.

### v1.2 Gap Closure
- **Segment 520 photo fallback:** First segment has 0 photos (earliest photo at mile 5.51). Renders with gradient fallback hero — intentional behavior, correctly implemented.

**Total: 4 items across 3 phases**

## Build Pipeline

8-step pipeline verified end-to-end:

```
1. parse-gpx              → route-data.json
2. resolve-annotations    → annotations.json
3. compute-sector-elevations → sector-elevations.json  [Phase 19]
4. generate-thumbnails    → public/thumbs/*.webp
5. copy-images
6. process-historical     → historical-photos.json     [Phase 18]
7. match-photos           → photos.json
8. copy-gpx
```

All steps execute in correct dependency order. Pipeline runs as `prebuild`/`predev` in package.json. Full build completes cleanly with zero errors.
