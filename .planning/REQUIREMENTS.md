# Requirements: Hiawatha's Revenge v1.7

**Defined:** 2026-04-07
**Core Value:** Visitors experience the beauty and scale of the Hiawatha's Revenge route through an immersive, visually stunning showcase that inspires them to ride it and support MBTN.

## v1.7 Requirements

Requirements for UX Polish & Photo Pipeline milestone.

### Map

- [ ] **MAP-01**: Route track displays two colors only — one for gravel sectors, one for all other road
- [ ] **MAP-02**: Surface-type legend/coloring removed from map

### Downloads

- [ ] **DL-01**: GPX download area text directs users to route selector for alternate route downloads

### Panels

- [ ] **PNL-01**: "View in route guide" button removed from sector detail panels

### Photos

- [ ] **PHT-01**: Segment card photos displayed in multi-column layout, each column ≤400px wide
- [ ] **PHT-02**: New photos processed through build pipeline (WebP thumbnails, optimized)
- [ ] **PHT-03**: New photos appear on map at tagged mileage points
- [ ] **PHT-04**: New photos appear in gallery
- [ ] **PHT-05**: Gallery photos ordered by route mileage (start to finish)
- [ ] **PHT-06**: Thumbnail aspect ratios preserved in all display contexts (no CSS stretching)

## Future Requirements

None deferred.
